FText::Resolve()

← 公开 API

Resolve(): 1. Manager = FTextManager::Get() // 单例 2. Translated = Manager.FindTranslation(Namespace, Key, Manager.GetCulture()) 3. return Translated ? *Translated : Source // 无译文回退 Source

FTextManager::ExecuteStage(ETextStage Stage)

← 公开 API

ExecuteStage(Stage): 1. lock(Mutex) 2. switch Stage: Init: Catalog.clear(); CurrentCulture = "en-US" Shutdown: Catalog.clear() 3. return true

MakeKey(Namespace, Key, Culture)（内部）

匿名命名空间，目录键构造

MakeKey(N, K, C): 1. return N + "\x1f" + K + "\x1f" + C // US 分隔防 "a"+"bc" == "ab"+"c"

LoadTranslationsFromJson(string_view)

← 公开 API

LoadTranslationsFromJson(JsonText): 1. Root = Json::FJsonValue::parse(JsonText) 2. for Entry in Root: AddTranslation(Entry.Namespace, Entry.Key, Entry.Culture, Entry.Text)
