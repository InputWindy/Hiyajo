FConsoleVariable::ExecuteStage(EConsoleVariableStage Stage)

← 公开 API · bool

阶段分发：Shutdown 清空注册表；Init 不动（静态 CVar 须存活）。

ExecuteStage(Stage): 1. if Stage == Shutdown: lock(GMutex) Registry.clear() 2. return true

FConsoleVariable::Find(std::string_view Name)

← 公开 API · IConsoleVariable*

加锁按名查找，命中返回裸指针，否则 nullptr。

Find(Name): 1. lock(GMutex) 2. It = Registry.find(string(Name)) 3. return It != end ? It->second.get() : nullptr

FConsoleVariable::Register(Name, Type, DefaultValue, Description, Flags)

← 公开 API · IConsoleVariable*

构造 FCVarEntry 插入注册表并返回接口。

Register(...): 1. lock(GMutex) 2. Entry = make_unique<FCVarEntry>(...) // 值内部存字符串 3. Result = Entry.get() 4. Registry[string(Name)] = move(Entry) 5. return Result

FCVarEntry（具体 IConsoleVariable）

← 公开 API · 匿名命名空间

字符串存储 + 类型化解析。

GetInt() → try std::stoi(Value) catch → 0 GetFloat() → try std::stof(Value) catch → 0.0f GetBool() → ToLower(Value) in {"true","1","yes","on"} GetString()→ return Value Set(V) → if HasFlag(Flags, ReadOnly): return else Value = string(V)
