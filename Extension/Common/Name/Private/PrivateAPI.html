FNamePool::ExecuteStage(ENameStage Stage)

← 公开 API · bool

ExecuteStage(Stage): 1. lock GPoolMutex 2. switch Stage: case Init: GPool.clear(); GLookup.clear() GPool.emplace_back() // 预留 index 0 = None case Shutdown: GPool.clear(); GLookup.clear() 3. return true

FNamePool::Intern(string_view Str)

← 公开 API · FName

Intern(Str): 1. if Str.empty(): return FName(0) 2. lock GPoolMutex 3. if GPool.empty(): GPool.emplace_back() // 懒预留 index 0 4. if GLookup 命中 Str: return FName(缓存 Id) 5. Id = GPool.size() 6. GPool.emplace_back(Str) 7. GLookup[GPool.back()] = Id 8. return FName(Id)
