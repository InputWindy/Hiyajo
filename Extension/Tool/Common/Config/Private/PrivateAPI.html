FConfig::ExecuteStage(EConfigStage Stage)

← 公开 API · bool

阶段分发：Init / Shutdown 均清空所有 section。

ExecuteStage(Stage): 1. if Stage == Init or Shutdown: Sections.clear() 2. return true

FConfig::Load(string_view Path)

← 公开 API · bool

逐行解析 INI。空行/`;`/`#` 跳过；`[section]` 切段；`key=value` 存 map。

Load(Path): 1. open ifstream(Path); if fail return false 2. CurrentSection = "" 3. for each Line: T = Trim(Line) if T empty or starts ';'/'#' : continue if T starts '[' and ends ']': CurrentSection = T[1:-1]; continue i = T.find('='); if npos: continue Sections[CurrentSection][Trim(T[:i])] = Trim(T[i+1:]) 4. return true

FConfig::GetString(Section, Key)

← 公开 API · optional<string>

GetString(Section, Key): 1. it = Sections.find(Section); if end return nullopt 2. k = it->second.find(Key); if end return nullopt 3. return k->second

FConfig::GetInt(Section, Key, Default)

← 公开 API · int64_t

GetInt(S, K, Def): 1. V = GetString(S, K); if !V return Def 2. try return std::stoll(*V) 3. catch return Def

FConfig::GetFloat(Section, Key, Default)

← 公开 API · double

GetFloat(S, K, Def): 1. V = GetString(S, K); if !V return Def 2. try return std::stod(*V) 3. catch return Def

FConfig::GetBool(Section, Key, Default)

← 公开 API · bool

GetBool(S, K, Def): 1. V = GetString(S, K); if !V return Def 2. Lower = lowercase(*V) 3. return Lower in {"true","1","yes","on"}

FConfig::SetString(Section, Key, Value)

← 公开 API · void

SetString(S, K, Value): 1. Sections[S][K] = move(Value)

FConfig::HasSection / HasKey

← 公开 API · bool

HasSection(S): 1. return Sections.find(S) != end HasKey(S, K): 1. return GetString(S, K).has_value()
