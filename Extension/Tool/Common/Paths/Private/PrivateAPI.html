FPaths::Resolve(string_view VirtualPath)

← 公开 API · path

Resolve(VirtualPath): 1. Sep = VirtualPath.find_first_of("/:") 2. if Sep == npos: if Roots 命中 VirtualPath: return Roots[VirtualPath] return path(VirtualPath) // 原样 3. Alias = VirtualPath.substr(0, Sep) 4. if Roots 未命中 Alias: return path(VirtualPath) 5. Result = Roots[Alias] 6. Result /= VirtualPath.substr(Sep + 1) 7. return Result

FPaths::HasRoot(string_view Alias)

← 公开 API · bool

HasRoot(Alias): 1. return Roots.find(Alias) != Roots.end()
