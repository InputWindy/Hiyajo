FTimer::ExecuteStage(ETimerStage Stage)

← 公开 API · bool

阶段分发：Init / Shutdown 都清空计时树。

ExecuteStage(Stage): 1. switch Stage: case Init / Shutdown: Reset() 2. return true

FTimer::BeginScope(string_view Name)

← 公开 API · void

BeginScope(Name): 1. Child = Current->Children[Name] // 建/取子节点 2. Child.Name = Name 3. Child.Start = steady_clock::now() 4. Current = &Child // 下移

FTimer::EndScope()

← 公开 API · void

EndScope(): 1. if Current == &Root: return // 不平衡，忽略 2. Elapsed = now() - Current->Start 3. Current->TotalSeconds += Elapsed 4. Current->MaxSeconds = max(MaxSeconds, Elapsed) 5. Current->Count++ 6. Current = Current->Parent // 回父节点

FTimer::Reset()

← 公开 API · void

Reset(): 1. Root = FNode{"Root"} 2. Current = &Root

FTimer::DumpToString()

← 公开 API · string

DumpToString(): 1. 递归 Format(Node, Depth): - 输出缩进 + Name + ": " - 若 Count > 0: 输出 Total*1000 ms (Count calls, avg, max) - 遍历 Children 递归 Format(Child, Depth+1) 2. Format(Root, 0) 3. 返回结果

FGameClock::GetGameSeconds()

← 公开 API · double

GetGameSeconds(): 1. Now = now() 2. if !bPaused: RealDelta = Now - LastReal GameSeconds += RealDelta * TimeScale DeltaSeconds = RealDelta * TimeScale 3. LastReal = Now 4. return GameSeconds

FGameClock::GetDeltaSeconds()

← 公开 API · double

GetDeltaSeconds(): 1. GetGameSeconds() // 先推进 2. return DeltaSeconds

FGameClock::SetPaused(bool bInPaused)

← 公开 API · void
