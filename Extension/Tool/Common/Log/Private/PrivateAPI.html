FLog::ExecuteStage(ELogStage Stage)

← 公开 API · bool

阶段分发：Init 时设全局级别 info；Shutdown 时先 flush 再关 spdlog。

ExecuteStage(Stage): 1. switch Stage: case Init: spdlog::set_level(spdlog::level::info) case Shutdown: if spdlog::default_logger() != nullptr: spdlog::default_logger()->flush() // GUI 退出前 flush 缓冲 spdlog::shutdown() 2. return true

SetLogLevel(ELogLevel Level)

← 公开 API · void

把插件的 ELlogLevel 枚举映射到 spdlog 级别。

SetLogLevel(Level): 1. switch Level: Debug → spdlog::level::debug Info → spdlog::level::info Warn → spdlog::level::warn Error → spdlog::level::err Off → spdlog::level::off 2. spdlog::set_level(映射结果)
