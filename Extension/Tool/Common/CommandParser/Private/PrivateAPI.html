FCommandParser::ExecuteStage(ECommandParserStage Stage)

← 公开 API · bool

阶段分发：Init / Shutdown 都清空 store。

ExecuteStage(Stage): 1. switch Stage: case Init: Storage.clear() case Shutdown: Storage.clear() 2. return true

FCommandParser::Find(std::string_view Name)

← 公开 API · const std::string*

Find(Name): 1. It = Storage.find(string(Name)) 2. return It != end ? &It->second : nullptr

FCommandParser::Has(std::string_view Name)

ParseCommandLine(int Argc, char** Argv)

← 公开 API · void

把 argc/argv 解析进单例 store。支持 -name=value、-name value、无值开关 -name。

ParseCommandLine(Argc, Argv): 1. if Argv == nullptr: return 2. Parser = FCommandParser::Get(); Parser.Reset() 3. for I in 1..Argc-1: Token = Argv[I] (剔除空指针) 4. 去掉前导 '-' 和 '--'；若为空 continue 5. if Token 含 '=': Name = '='前, Value = '='后 → Storage[Name]=Value 6. else: Name = Token if I+1 有效 且 argv[I+1] 不以 '-' 开头: Storage[Name] = argv[I+1]; ++I else: Storage[Name] = "" // 无值开关
