Maho — API 文档

引擎壳层：两个抽象基类 + 入口。入口：Maho.h（聚合头）· 概念见 Maho.md

Stage 枚举

ESingletonStageenum class

单例生命周期（2 值），驱动 FSingletonRegistryBase（串行调度）。

成员变量

成员说明
Init = 0初始化（正序）
Shutdown = 1卸载（逆序，配合 FReverseTopology）

EEngineStageenum class

引擎生命周期（9 值），驱动 FEngineBase（并行调度）。

成员变量

成员说明
PreInit = 0, Init, PostInit启动三阶段（正序）
PreTick, Tick, PostTick帧循环三阶段
PreShutdown, Shutdown, PostShutdown退出三阶段（逆序，配合 FReverseTopology）

FSingletonRegistryBase

FSingletonRegistryBaseclass

Pre-app 单例注册表：串行驱动（无线程池）。抽象基类——项目侧 code-gen 生成具体子类， 继承 FExtensions<...> 静态装配，并在派生构造/析构体里调 Init/Shutdown。

接口

签名说明
virtual ~FSingletonRegistryBase() virtual 虚析构（经基类指针安全删除）
virtual void Init() = 0 virtual protected 纯虚：正序驱动 Execute<Init, FList>()
virtual void Shutdown() = 0 virtual protected 纯虚：逆序驱动 Execute<Shutdown, FList, FReverseTopology>()

基类继承 TSerialScheduler<ESingletonStage>（Execute 公开可调）。构造 protected。

FEngineBase

FEngineBaseclass

App 引擎基类：并行驱动（自持线程池）。多继承 TParallelScheduler<EEngineStage> + IRunable。 MainLoop 是 final 模板方法，驱动 9 个纯虚 stage；项目侧只实现 stage + 装配 FExtensions。

接口

签名说明
virtual ~FEngineBase() virtual 虚析构（经 IRunable* 安全删除）
void MainLoop() final override final 模板方法：启动三阶段 → Tick 循环 → 退出三阶段。项目类不可覆写

Stage 虚函数（protected，项目侧实现）

签名说明
virtual void PreInit() = 0 protected驱动 Execute<PreInit, FList>
virtual void Init() = 0 protected驱动 Execute<Init, FList>
virtual void PostInit() = 0 protected驱动 Execute<PostInit, FList>
virtual void PreTick() = 0 protected驱动 Execute<PreTick, FList>
virtual void Tick() = 0 protected驱动 Execute<Tick, FList>
virtual void PostTick() = 0 protected驱动 Execute<PostTick, FList>
virtual void PreShutdown() = 0 protected驱动 Execute<PreShutdown, FList, FReverseTopology>
virtual void Shutdown() = 0 protected驱动 Execute<Shutdown, FList, FReverseTopology>
virtual void PostShutdown() = 0 protected驱动 Execute<PostShutdown, FList, FReverseTopology>
void RequestShutdown() protected extension 在 Tick 中调用，置 CurrentStage 退出主循环

成员变量

字段类型说明
CurrentStage privateEEngineStage退出标记（初值 PreInit，RequestShutdown 置 PreShutdown）

EntryPoint — 平台入口

EntryPoint.hheader

定义 main / WinMain。游戏项目单 .cpp include。项目侧实现两个工厂。

项目侧契约（code-gen 生成）

签名说明
FSingletonRegistryBase* CreateSingletonRegistry(int Argc, char** Argv) new 具体 registry 子类；entry point 用 unique_ptr 持有（RAII）
IRunable* CreateEngine(int Argc, char** Argv) new 具体引擎子类，转 IRunable* 返回

入口流程

步骤说明
InstallFatalHandlers()装 std::terminate 兜底（早于一切）
unique_ptr<FSingletonRegistryBase>ctor 跑 Init，dtor 跑 Shutdown
CreateEngine(Argc, Argv) → MainLoop()驱动引擎主循环
try/catch → ReportFatal逃逸异常兜底（stderr + Fatal.log + abort）

相关类型

IRunableinterface

可运行契约（virtual void MainLoop() = 0）。见 Async/Async.html。

FExtensions<TExtensions...>template

静态装配载体（using FList = TTypeList<...>）。见 Core/Core.html。
