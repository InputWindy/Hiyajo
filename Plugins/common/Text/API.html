Text — API

本地化文本单例服务——FText 文本句柄 + FTextManager 翻译目录。SetCulture 切文化，FText::Resolve() 查当前文化翻译、缺失回退源文本。Get() 定义在 Text.dll。nlohmann/json（引擎三方）用于 LoadTranslationsFromJson。

Culture — 文化常量

Culturenamespace（inline constexpr）

支持的文化常量。字符串均为 UTF-8——"支持"指目录可以持有这些文化，引擎不内置转换。

常量说明
English = "en-US"英文（默认文化）
Chinese = "zh-CN"简体中文
Japanese = "ja-JP"日文

FText — 文本句柄

FTextclass

本地化文本句柄——存 {Namespace, Key, Source}。相等比较只看 Namespace + Key。

签名说明
FText()默认构造（空）
FText(std::string Namespace, std::string Key, std::string Source)构造句柄
std::string_view GetNamespace() / GetKey() / GetSource()读取三元组
std::string Resolve()按当前文化查翻译；无则回退 Source
operator==Namespace + Key 相等

FTextManager — 目录管理器

FTextManagerclass : TSingleton<FTextManager>, IPlugin<IInit, IShutdown>

当前文化 + 翻译目录。目录 key = Namespace + 0x1f + Key + 0x1f + Culture（分隔符防拼接碰撞），Mutex 保护、线程安全。

签名说明
static FTextManager& Get()进程唯一访问器——定义在 Text.cpp
void Initialize(int, char**) override清目录 + 重置文化为 en-US
void Shutdown() override清目录
std::string_view GetCulture()当前文化
void SetCulture(std::string)切换文化
void AddTranslation(Namespace, Key, Culture, std::string Text)注册一条翻译（线程安全）
void LoadTranslationsFromJson(std::string_view)加载 JSON 数组 [{Namespace, Key, Culture, Text}, ...]
const std::string* FindTranslation(Namespace, Key, Culture)查询翻译；无则 nullptr（线程安全）
