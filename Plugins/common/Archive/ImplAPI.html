FArchive& FArchive::operator<<(std::string& V)

← 公开 API · FArchive&

字符串序列化——先写 uint32 长度（长度前缀），读模式据此 resize 缓冲，再写/读全部字节。长度前缀保证跨端可恢复。

operator<<(string V): 1. Len = V.size(); 写 Len (uint32) 2. if 读模式: V.resize(Len) 3. if Len > 0: Serialize(V.data(), Len) 4. return *this

FMemoryReader（读端）

FMemoryReader::FMemoryReader(const std::vector<std::uint8_t>& InData)

← 公开 API · 构造

读模式构造——拷贝输入字节为内部缓冲，游标 Pos 从 0 起。

FMemoryReader(InData): 1. FArchive(Read 模式) 2. Data = InData (Pos = 0)

void FMemoryReader::Serialize(void* Out, std::size_t Size)

← 公开 API · void

顺序读 Size 字节到 Out——越界直接返回（TODO 报错），否则 memcpy 并推进游标。

Serialize(Out, Size): 1. if Pos + Size > Data.size(): return // 越界保护 2. memcpy(Out, Data + Pos, Size) 3. Pos += Size

void FMemoryReader::Seek(std::size_t InPos)

← 公开 API · void

绝对定位游标（不做边界校验，靠 Serialize 兜底）。

Seek(InPos): 1. Pos = InPos

std::size_t FMemoryReader::Tell() const

← 公开 API · std::size_t

返回当前读游标位置。

Tell(): 1. return Pos

FMemoryWriter（写端）

FMemoryWriter::FMemoryWriter()

← 公开 API · 构造

写模式构造——内部缓冲从空开始。

FMemoryWriter(): 1. FArchive(Write 模式) 2. Buffer 为空

void FMemoryWriter::Serialize(void* In, std::size_t Size)

← 公开 API · void

顺序追加写——Buffer 尾部扩容后 memcpy 拷贝入。

Serialize(In, Size): 1. Old = Buffer.size() 2. Buffer.resize(Old + Size) 3. memcpy(Buffer + Old, In, Size)

void FMemoryWriter::Seek(std::size_t InPos)

← 公开 API · void

截断式定位——目标位置小于当前缓冲则 resize 回退（回写覆盖旧数据用）。

Seek(InPos): 1. if InPos < Buffer.size(): Buffer.resize(InPos)

std::size_t FMemoryWriter::Tell() const

← 公开 API · std::size_t

返回已写字节数（即缓冲长度）。

Tell(): 1. return Buffer.size()

const std::vector<std::uint8_t>& FMemoryWriter::GetBytes() const

← 公开 API · const std::vector<std::uint8_t>&

只读视图——不拷贝，直接引用内部缓冲。

GetBytes(): 1. return Buffer

std::vector<std::uint8_t> FMemoryWriter::TakeBytes()

← 公开 API · std::vector<std::uint8_t>

转移所有权——move 出缓冲，Writer 变空，零拷贝交付结果。
