Archive — API

二进制序列化纯库——抽象读写流 + 内存字节流 + 自序列化接口。无单例、无状态、零三方，header-only。

EArchiveMode — 序列化方向

EArchiveModeenum class : uint8_t

归档读写方向——FArchive 构造时固定，运行期经 IsReading / IsWriting 查询。

值说明
Read = 0读模式（反序列化）
Write = 1写模式（序列化）

FArchive — 抽象读写流

FArchiveclass

原始字节与类型化数据之间的桥。虚接口 Serialize / Seek / Tell 由具体流实现；内建类型 + 通用 POD 模板走 operator<<。

签名说明
virtual ~FArchive()虚析构
bool IsReading() / IsWriting()方向查询
virtual void Serialize(void*, std::size_t) = 0原始字节读写（memcpy 语义）
virtual void Seek(std::size_t) = 0定位
virtual std::size_t Tell() = 0当前位置
FArchive& operator<<(int32_t/uint32_t/int64_t/uint64_t/float/double/bool&)内建类型序列化（memcpy 整块）
FArchive& operator<<(std::string&)字符串：前置 uint32 长度 + 内容
template<T> FArchive& operator<<(T&)通用 POD（static_assert trivially copyable，如 glm::vec3）

ISerialize — 自序列化接口

ISerializeclass

类型自己决定如何过归档——Serialize(FArchive&) 内把所有字段 Ar << 出去，同一函数同时处理读与写。

签名说明
virtual ~ISerialize()虚析构
virtual void Serialize(FArchive& Ar) = 0序列化全部字段（读或写）

FMemoryReader — 内存读取流

FMemoryReaderclass : FArchive

在已有字节 buffer 上读取——持 buffer 引用，buffer 必须比 reader 活得久。越界读静默跳过（TODO 报告）。

签名说明
explicit FMemoryReader(const std::vector<std::uint8_t>&)绑定外部 buffer（Read 模式）
void Serialize(void*, std::size_t) overridememcpy 读出，Pos 前进
void Seek(std::size_t) override重定位
std::size_t Tell() override当前读位置

FMemoryWriter — 内存写入流

FMemoryWriterclass : FArchive

累积到自持 buffer——GetBytes() 查看、TakeBytes() 移走所有权。

签名说明
FMemoryWriter()构造（Write 模式，空 buffer）
void Serialize(void*, std::size_t) override追加到 buffer
void Seek(std::size_t) override截断到指定大小（仅缩小）
std::size_t Tell() overridebuffer 当前大小
const std::vector<std::uint8_t>& GetBytes()查看字节（const 引用）
std::vector<std::uint8_t> TakeBytes()移走字节（所有权转移）
