校验

bool IsValidUtf8(std::string_view In)

← 公开 API · bool

手写 UTF-8 校验：逐字节扫描——ASCII 直过；按首字节前导位判定 2/3/4 字节序列，逐个检查续字节（10xxxxxx）并累积码点；拒绝截断、过短编码（overlong）、超范围 >0x10FFFF、以及代理区 0xD800-0xDFFF。

IsValidUtf8(In): 1. I = 0 2. while I < N: 3. C = In[I] 4. if C < 0x80: ++I; continue 5. 按 C 判定 Extra / 码点下限 / Mask: 6. 0xC0→1字节 / 0xE0→2 / 0xF0→3，否则 return false 7. if I+Extra ≥ N: return false // 截断 8. CP = C & Mask 9. for K in 1..Extra: 10. if 续字节非 10xxxxxx: return false 11. CP = (CP<<6) | (续 & 0x3F) 12. if CP < 下限 or CP > 0x10FFFF or 代理区: return false 13. I += Extra + 1 14. return true

转换（WinAPI）

std::u16string Utf8ToUtf16(std::string_view In)

← 公开 API · std::u16string

UTF-8 → UTF-16：先 MultiByteToWideChar 两次调用——第一遍取所需大小并校验非法字符（MB_ERR_INVALID_CHARS），第二遍实际转换。空输入直接返回空。

Utf8ToUtf16(In): 1. if In.empty(): return {} 2. Size = MultiByteToWideChar(CP_UTF8, MB_ERR_INVALID_CHARS, In, 0) 3. if Size ≤ 0: return {} 4. Out(Size); MultiByteToWideChar(CP_UTF8, 0, In, Out, Size) 5. return Out

std::string Utf16ToUtf8(std::u16string_view In)

← 公开 API · std::string

UTF-16 → UTF-8：WideCharToMultiByte 两遍——第一遍取大小，第二遍转换。

Utf16ToUtf8(In): 1. if In.empty(): return {} 2. Size = WideCharToMultiByte(CP_UTF8, 0, In, 0, null, null) 3. if Size ≤ 0: return {} 4. Out(Size); WideCharToMultiByte(CP_UTF8, 0, In, Out, Size) 5. return Out

std::u32string Utf8ToUtf32(std::string_view In)

← 公开 API · std::u32string

UTF-8 → UTF-32：先转 UTF-16，再逐 16 位单元手工解代理对——高代理+低代理合并成码点；孤立代理直接返回空（非法）。

Utf8ToUtf32(In): 1. U16 = Utf8ToUtf16(In) 2. for I in U16: 3. Unit = U16[I] 4. if 高代理且后随低代理: 5. CP = 0x10000 + (高-0xD800)<<10 + (低-0xDC00) 6. 入 Out; ++I 7. elif 孤立代理: return {} // 非法 8. else: 直接入 Out 9. return Out

std::string Utf32ToUtf8(std::u32string_view In)

← 公开 API · std::string

UTF-32 → UTF-8：先按码点编码代理对（<0x10000 直接入，否则拆高/低代理），再转 UTF-8。

Utf32ToUtf8(In): 1. for CP in In: 2. if CP < 0x10000: U16 += CP 3. else: CP -= 0x10000 4. U16 += 0xD800 + (CP>>10) 5. U16 += 0xDC00 + (CP&0x3FF) 6. return Utf16ToUtf8(U16)

平台对接

FNativeString ToNative(std::string_view Utf8) / std::string FromNative(FNativeStringView Native)

← 公开 API · 平台宽字符串

Win：UTF-8 ↔ 原生宽字符串（wstring），经 UTF-16 中转；非 Win：原样拷贝。

ToNative(Utf8): U16 = Utf8ToUtf16(Utf8); return wstring(U16) FromNative(Native): U16 = (Native); return Utf16ToUtf8(U16)

EnsureConsoleUtf8(): 1. #if _WIN32: SetConsoleOutputCP(CP_UTF8)
