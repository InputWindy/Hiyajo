Unicode — API

UTF-8/16/32 + 平台原生转换纯库——零三方、无单例、纯自由函数。引擎内部字符串恒为 UTF-8 std::string，只在平台边界转换（Windows：UTF-16 经 WinAPI；其他：passthrough）。

类型别名

FNativeString / FNativeStringViewusing（平台相关）

平台原生字符串类型。Windows = std::wstring(_view)；其他平台 = std::string(_view)。

签名说明
using FNativeString = std::wstring // _WIN32Windows：宽字符串
using FNativeString = std::string // 其他其他平台：UTF-8 直通

自由函数

IsValidUtf8自由函数

校验良构 UTF-8——拒绝孤立代理 / overlong / 越界码点（> 0x10FFFF）/ 截断序列 / 坏续字节。

签名说明
bool IsValidUtf8(std::string_view)输入是否为良构 UTF-8

Utf8ToUtf16 / Utf16ToUtf8 / Utf8ToUtf32 / Utf32ToUtf8自由函数

UTF-8 ↔ UTF-16 ↔ UTF-32 互转。Windows 上经 WinAPI（MultiByteToWideChar / WideCharToMultiByte）；非 Windows 为最佳努力 passthrough（Windows 是主目标）。UTF-32 转换经 UTF-16 代理对。

签名说明
std::u16string Utf8ToUtf16(std::string_view)UTF-8 → UTF-16
std::string Utf16ToUtf8(std::u16string_view)UTF-16 → UTF-8
std::u32string Utf8ToUtf32(std::string_view)UTF-8 → UTF-32
std::string Utf32ToUtf8(std::u32string_view)UTF-32 → UTF-8

ToNative / FromNative / EnsureConsoleUtf8自由函数

平台边界转换：UTF-8 ↔ 平台原生（Windows：UTF-16；其他：passthrough）；控制台 UTF-8 输出。

签名说明
FNativeString ToNative(std::string_view Utf8)UTF-8 → 平台原生
std::string FromNative(FNativeStringView)平台原生 → UTF-8
void EnsureConsoleUtf8()Windows：SetConsoleOutputCP(CP_UTF8)；其他平台 no-op
