FName FNamePool::Intern(std::string_view Str)

← 公开 API · FName

登记字符串：空串返回默认 FName；持锁查 Lookup——命中直接复用旧 Id，未命中则追加到 Pool 并建反查。返回 Id 包装的 FName。

Intern(Str): 1. if Str.empty(): return FName{} 2. lock(Mutex): 3. It = Lookup.find(Str) 4. if 命中: return FName{It->second} 5. NextId = Pool.size() 6. Pool.emplace_back(Str) 7. Lookup[Pool.back()] = NextId 8. return FName{NextId}
