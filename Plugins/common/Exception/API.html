Exception — API

非致命异常广播单例服务——ReportException 把消息分发到所有 OnException 订阅者（日志、遥测、崩溃上报）。本插件绝不 abort——致命错误走 Core/Fatal。Get() 定义在 Exception.dll。纯 std。

TMulticastEvent — 多播事件

TMulticastEvent<void(Args...)>class

最小多播事件（bind + broadcast）——引擎暂无独立委托积木，OnException 只需要 void(const std::string&) 广播。无锁，单线程广播语义。

签名说明
using FHandler = std::function<void(Args...)>处理器类型
void Bind(FHandler)追加订阅者
void Broadcast(Args...) const顺序调用非空 handler
void RemoveAll()清空订阅者

FException — 报告入口

FExceptionclass : TSingleton<FException>, IPlugin<IInit, IShutdown>

非致命异常处理单例。Initialize/Shutdown 清空订阅（RemoveAll）。

签名说明
static FException& Get()进程唯一访问器——定义在 Exception.cpp
void Initialize(int, char**) override清订阅
void Shutdown() override清订阅
void ReportException(std::string_view)报告非致命异常（广播到 OnException）
void ReportException(const std::exception&)从 std::exception 报告（转发 what()）
TMulticastEvent<void(const std::string&)> OnException订阅事件——每个被报告的异常消息都会送达
