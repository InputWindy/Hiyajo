← 公开 API · void

Shutdown(): 1. FThreadedServer::Shutdown() // 停 + join IO 线程 2. lock(Impl->Mutex): PendingIO.clear() PendingExports.clear() Catalog.clear()

IO 传输

FResourceSystem::RequestLoad(std::string Path)

内部 · FTransferHandle

提交一个读盘任务到 IO 线程：打开文件读全部字节入 Bulk，成功/失败经 atomic 标记。返回句柄供轮询。

RequestLoad(Path): 1. State = new FTransferState 2. Submit(IO 线程): Bulk = 读文件全部字节 (ifstream binary) lock(State->Mutex): State->Bulk = Bulk 非空 → State->bSucceeded = true (release) 否则 → State->bFailed = true (release) 3. return FTransferHandle(State)

FResourceSystem::EnqueueImport(SourcePath, AssetPath, OnBulkReady)

内部 · bool

虚拟路径经 FPaths 解析为物理路径 → RequestLoad 读盘 → 挂到 PendingIO（按 AssetPath 去重 key）。IO 线程读盘，游戏线程解码。

EnqueueImport(SourcePath, AssetPath, OnBulkReady): 1. Physical = FPaths::Resolve(SourcePath) 2. Handle = RequestLoad(Physical) 3. lock(Impl->Mutex): PendingIO[FName(AssetPath)] = { Handle, OnBulkReady } 4. return true

FResourceSystem::EnqueueExport(Bytes, DestinationPath, OnDone)

内部 · bool

把已编码字节提交到 IO 线程写盘（WriteBytes）；完成后 atomic 标记。OnDone 挂 PendingExports（游戏线程 Tick 时回传）。编码在调用线程完成（不跨线程读共享资源）。

EnqueueExport(Bytes, Dest, OnDone): 1. State = new FTransferState 2. Submit(IO 线程): bWritten = WriteBytes(Dest, Bytes) 成功 → State->bSucceeded = true (release) 失败 → State->bFailed = true (release) 3. lock(Impl->Mutex): PendingExports[FName(Dest)] = { Handle, OnDone } 4. return true

Catalog

内部 · const FResource*

RegisterResource(AssetPath, Resource): 1. Raw = Resource.get() 2. lock(Impl->Mutex): Catalog[FName(AssetPath)] = move(Resource) 3. return Raw

Find(AssetPath): 1. lock(Impl->Mutex): It = Catalog.find(FName(AssetPath)) 2. return It != end ? It->second.get() : nullptr

轮询（Tick 内）

FResourceSystem::ProcessReadyIO()

内部 · void

游戏线程轮询挂起传输。**全程持 Impl 锁**（IO 线程 EnqueueImport/Export 并发写 PendingIO/PendingExports——不持锁遍历/erase 是数据竞争）。import：完成（成功/失败）→ 从 PendingIO 取出 → 锁内调 OnBulkReady（成功传 Bulk 字节 / 失败传空 span），每 tick 限 kMaxAppliesPerTick 个；export：完成 → 取出 → OnDone(是否成功)。

ProcessReadyIO(): 1. lock(Impl->Mutex) // 全程持锁 2. 遍历 PendingIO（每 tick ≤ kMaxAppliesPerTick）: if 未完成: continue 取出 + erase lock(State->Mutex): // Bulk 快照 成功 → OnBulkReady(Bulk.Bytes) // 解码，游戏线程 失败 → OnBulkReady({}) // 空 span 3. 遍历 PendingExports: if 未完成: continue 取出 + erase OnDone(Handle.HasSucceeded())

FResourceSystem::WriteBytes(PhysicalPath, Bytes)

内部 · bool

物理路径写盘（ofstream binary）。返回写入是否成功（流状态）。

WriteBytes(Path, Bytes): 1. Stream = ofstream(Path, binary) 2. if !Stream: return false 3. Stream.write(Bytes.data(), Bytes.size()) 4. return bool(Stream)
