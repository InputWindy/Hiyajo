Compress — API

zstd 压缩/解压纯库——无状态、无单例、静态自由函数，失败返回 nullopt（不抛异常）。底层 zstd（引擎三方编译 C 静态库，经 Maho PUBLIC 链接）。

自由函数

Compress自由函数

zstd 压缩字节流。Level 为 zstd 的 1..22（0 = 默认；负数/快速模式不支持）。目标过小或编码器错误返回 nullopt。

签名说明
std::optional<std::vector<std::uint8_t>> Compress(const std::vector<std::uint8_t>& Data, int Level = 0)压缩；空输入返回空 vector；失败 nullopt

Decompress自由函数

解压 zstd payload——输入非合法 zstd 或解压大小不可算/不合理时返回 nullopt。

签名说明
std::optional<std::vector<std::uint8_t>> Decompress(const std::vector<std::uint8_t>& Data)解压还原原始字节

GetDecompressedSize自由函数

zstd payload 已知时的解压后大小——损坏输入失败（nullopt）。

签名说明
std::optional<std::size_t> GetDecompressedSize(const std::vector<std::uint8_t>& Data)解压后字节数（帧内容大小）
