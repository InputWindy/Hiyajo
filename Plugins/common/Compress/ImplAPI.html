压缩 / 解压

std::optional<std::vector<std::uint8_t>> Compress(const std::vector<std::uint8_t>& Data, int Level)

← 公开 API · std::optional<std::vector<std::uint8_t>>

ZSTD 压缩：空输入返回空数组；按 ZSTD_compressBound 预分配输出缓冲，ZSTD_compress 压缩后 resize 到实际写入长度。任何一步报错（ZSTD_isError）返回 nullopt。

Compress(Data, Level): 1. if Data.empty(): return {} 2. Bound = ZSTD_compressBound(Data.size()) 3. if ZSTD_isError(Bound): return nullopt 4. Out(Bound); Written = ZSTD_compress(Out, Bound, Data, Level) 5. if ZSTD_isError(Written): return nullopt 6. Out.resize(Written); return Out

std::optional<std::vector<std::uint8_t>> Decompress(const std::vector<std::uint8_t>& Data)

← 公开 API · std::optional<std::vector<std::uint8_t>>

ZSTD 解压：先从帧头取解压后大小精确分配缓冲（免扩容），ZSTD_decompress 后 resize 到实际字节数。取大小或解压失败返回 nullopt。

Decompress(Data): 1. SizeOpt = GetDecompressedSize(Data) 2. if !SizeOpt: return nullopt 3. Out(*SizeOpt); Written = ZSTD_decompress(Out, Size, Data) 4. if ZSTD_isError(Written): return nullopt 5. Out.resize(Written); return Out

std::optional<std::size_t> GetDecompressedSize(const std::vector<std::uint8_t>& Data)

← 公开 API · std::optional<std::size_t>

读 ZSTD 帧头获取内容大小（content size）。错误 / 无内容大小（CONTENTSIZE_ERROR/UNKNOWN）返回 nullopt。

GetDecompressedSize(Data): 1. Size = ZSTD_getFrameContentSize(Data) 2. if ZSTD_isError(Size) or Size ∈ {ERROR, UNKNOWN}: return nullopt 3. return Size
