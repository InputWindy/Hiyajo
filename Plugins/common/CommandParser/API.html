CommandParser — API

命令行参数解析单例服务——argc/argv → key-value 存储。支持 --key value 与 --key=value；裸 flag 记为 true。底层 CLI11（引擎三方，header-only）。Get() 定义在 CommandParser.dll。

FCommandParser — 命令行解析单例

FCommandParserclass : TSingleton<FCommandParser>, IPlugin<IInit, IShutdown>

把每个 -key 规范化为 --key 长选项后交给 CLI11 tokenize / 引号值处理，读回进 std::map<std::string, std::string> Store。坏输入不 abort（尽力读回已解析部分）。

签名说明
static FCommandParser& Get()进程唯一访问器——定义在 CommandParser.cpp
void Initialize(int Argc, char** Argv) override即 Parse(argc, argv)（幂等）
void Shutdown() override清空 Store
void Parse(int Argc, char** Argv)解析进 Store（幂等；后写覆盖）
bool Has(std::string_view Key)键是否出现（带不带值都算）
std::string Get(std::string_view Key)取值；无则空串
bool GetBool(std::string_view Key)true/1/yes/on → true
int GetInt(std::string_view Key)取整；缺失/不可解析回 0
const std::map<std::string, std::string>& GetAll()全部 key→value（const 引用）
void Clear()重置 Store
