void FCommandParser::Parse(int Argc, char** Argv)

← 公开 API · void

核心：把单横杠参数归一化为 CLI11 长选项再解析。逐参数处理——"−key"→"--key"；有 '=' 原样内联；后跟非横杠值则拼 "--key=value" 并跳过一个参数；裸 flag 补 "=true"。归一化后收集去重 key 声明 CLI11 option（expected(1)），parse 失败不中止，最后把非空结果回填 Store。

Parse(Argc, Argv): 1. Normalized = ["maho"] // 程序名占位 2. for I in 1..Argc: 3. Arg = Argv[I] 4. if 非 '-' 开头: continue 5. if 已是 '--': 原样保留 6. elif 含 '=': 追加 "--" + 去横杠 7. elif 后值是参数: "--key=value", ++I 8. else: "--key=true" // 裸 flag 9. Keys = 去重(Normalized 中每个 key 名), 排序 10. App = CLI::App; allow_extras 11. for Key: App.add_option("--"+Key)->expected(1) 12. try App.parse(Normalized) catch(ParseError){} // 容错 13. for Key: if 有结果: Store[Key] = 首个结果
