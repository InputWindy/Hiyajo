← 公开 API · IConsoleVariable*

新建 FCVarEntry 并登记——同 key 覆盖旧条目。返回裸指针给调用方。持 GMutex。

Register(Name, Type, DefaultValue, Description, Flags): 1. lock(GMutex): 2. Entry = make_unique<FCVarEntry>(...) 3. Result = Entry.get() 4. Registry[Name] = move(Entry) 5. return Result
