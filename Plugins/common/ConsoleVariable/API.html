ConsoleVariable — API

控制台变量注册表（UE IConsoleManager 风格）——静态 TAutoConsoleVariable 全局在 static-init 自注册，Find 按名查询。值以字符串存储、类型化访问时解析。Get() 定义在 ConsoleVariable.dll。纯 std。

枚举与标志

ECVarFlagsenum class : uint32_t

控制台变量标志（UE ECVF_* 风格），可按位组合。

值说明
None = 0无标志
Cheat = 1 << 0作弊专用
ReadOnly = 1 << 1运行时不可改（Set 静默忽略）

辅助函数

签名说明
constexpr bool HasFlag(ECVarFlags, ECVarFlags)按位检测标志

ECVarTypeenum class : uint8_t

控制台变量值类型。

值说明
Int / Float / Bool / String值类型（内部以字符串存储，访问时解析）

IConsoleVariable — 变量接口

IConsoleVariableclass

FindConsoleVariable 返回的接口。值以字符串内部存储、类型化访问时解析。

签名说明
virtual ~IConsoleVariable()虚析构
virtual std::string_view GetName() = 0变量名
virtual std::string_view GetDescription() = 0描述
virtual ECVarFlags GetFlags() = 0标志
virtual int GetInt() / float GetFloat() / bool GetBool() / std::string GetString() = 0类型化读取（解析失败回 0/false）
virtual void Set(std::string_view) = 0从字符串设置；ReadOnly 时忽略

FConsoleVariable — 注册表单例

FConsoleVariableclass : TSingleton<FConsoleVariable>, IPlugin<IInit, IShutdown>

变量注册表（std::map<std::string, unique_ptr<IConsoleVariable>>，Mutex 保护）。Shutdown 清注册表；Initialize 无事可做（static-init 已注册）——显式不清，全局变量须存活。

签名说明
static FConsoleVariable& Get()进程唯一访问器——定义在 ConsoleVariable.cpp
void Initialize(int, char**) override无操作（静态全局已自注册）
void Shutdown() override清注册表
IConsoleVariable* Find(std::string_view Name)按名查询；未注册返回 nullptr
IConsoleVariable* Register(Name, ECVarType, std::string DefaultValue, Description, ECVarFlags)注册（TAutoConsoleVariable 用）；返回接口

TAutoConsoleVariable — 静态自注册变量

TCVarType<T>struct 特化

类型 → ECVarType 映射：int / float / bool / std::string。

签名说明
static constexpr ECVarType Value对应值类型

TAutoConsoleVariable<T>class

静态控制台变量——构造即经 FConsoleVariable::Get().Register 自注册（static-init），像 UE 的 TAutoConsoleVariable。T = int / float / bool / std::string。

签名说明
TAutoConsoleVariable(Name, T Default, Description, Flags = None)构造即注册
T GetValue()类型化读取（按 TCVarType<T> 走对应 GetX）
void Set(T)转字符串后 Handle->Set
std::string_view GetName()变量名
