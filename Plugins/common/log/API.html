Log — API

日志单例服务——封装 spdlog 的线程安全 stdout-color logger，全引擎共享。fmt 风格格式化（{} 占位）。Get() 定义在 Log.cpp（编进 Log.dll），实例进程唯一。

FLog — 日志单例

FLogclass : TSingleton<FLog>, IPlugin<IInit, IShutdown>

CRTP 单例，包装 spdlog::logger。跨 DLL 经 FLog::Get()（非 header inline，避免每 DLL 一份）。

签名说明
static FLog& Get()进程唯一访问器——声明在头、定义在 Log.cpp（Log.dll）
std::shared_ptr<spdlog::logger> Logger共享 logger——所有引擎/服务日志路由到这里
void Initialize(int, char** Argv) override创建 stdout-color logger（"Maho"），设 pattern 与级别；识别 --log-level=trace|debug|info|warn|error
void Shutdown() overridespdlog::shutdown()（flush + drop）+ 释放 Logger
template<Args...> static void Info/Warn/Error(format_string_t<Args...>, Args...)fmt 风格静态透传（路由 Get().Logger，编译期格式检查）

宏

MAHO_LOG_CORE_TRACE / DEBUG / INFO / WARN / ERROR / CRITICAL宏

CORE 日志宏糖——直接透传到 ::Maho::FLog::Get().Logger 的对应级别方法。须在 FLog::Get().Initialize(argc, argv) 之后使用。

#define MAHO_LOG_CORE_INFO(...) ::Maho::FLog::Get().Logger->info(__VA_ARGS__)
#define MAHO_LOG_CORE_ERROR(...) ::Maho::FLog::Get().Logger->error(__VA_ARGS__)
// TRACE / DEBUG / WARN / CRITICAL 同理
