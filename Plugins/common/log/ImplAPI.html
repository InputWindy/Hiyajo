void FLog::Initialize(int, char** Argv) （header 内联）

← 公开 API · void

内联在 Log.h：创建线程安全 stdout 彩色 logger（"Maho"），设格式；扫命令行 --log-level=trace|debug|info|warn|error 设级别，缺省 debug。

Initialize(Argc, Argv): 1. Logger = spdlog::stdout_color_mt("Maho") 2. Logger->set_pattern("[%Y-%m-%d %H:%M:%S.%e] [%^%l%$] %v") 3. Lv = debug 4. for i in Argv: 5. if Argv[i] 为 "-log-level" 且下个参数存在: 6. Lv = spdlog::level::from_str(Argv[i+1]) 7. Logger->set_level(Lv)

void FLog::Shutdown() （header 内联）

← 公开 API · void

内联在 Log.h：flush + 停掉全部 spdlog registry，释放 Logger。

Shutdown(): 1. spdlog::shutdown() 2. Logger.reset()
