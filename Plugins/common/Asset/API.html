Asset — API

资产注册表单例服务——逻辑路径（/Game/...）→ 资产元数据。Scan 递归索引 content 目录，Find 按逻辑路径查询，Resolve 经 FPaths 映射物理文件。Get() 定义在 Asset.dll。依赖插件：Paths。

EAssetType — 资产类型

EAssetTypeenum class : uint8_t

资产类型（可扩展；由磁盘扩展名推断）。

值说明
Unknown = 0未知类型
Material材质（.material）
Texture纹理（.texture）

FAssetPath — 逻辑资产路径

FAssetPathclass

逻辑资产路径——无扩展名、无对象部分（本引擎无 UObject 系统）。默认构造空；可作 map key。

签名说明
FAssetPath()默认构造（空路径）
explicit FAssetPath(std::string)从逻辑路径字符串构造
std::string_view GetPath()逻辑路径
operator== / != / <字符串比较（可作有序/无序容器 key）

FAssetData — 资产元数据

FAssetDatastruct

已解析的资产元数据。Dependencies 由反序列化填充（延迟解析）。

签名说明
FAssetPath Path逻辑路径
EAssetType Type = Unknown资产类型
std::filesystem::path File物理文件（如 Content/Materials/M_Metal.material）
std::vector<FAssetPath> Dependencies依赖（反序列化填充）

FAssetRegistry — 注册表单例

FAssetRegistryclass : TSingleton<FAssetRegistry>, IPlugin<IInit, IShutdown>

资产注册表：逻辑路径字符串 → 元数据（std::map<std::string, FAssetData>，Mutex 保护）。

签名说明
static FAssetRegistry& Get()进程唯一访问器——定义在 Asset.cpp
void Initialize(int, char**) override清 Assets
void Shutdown() override清 Assets
void Scan(const std::filesystem::path& ContentDir, std::string_view MountAlias = "Game")递归索引 content 目录；MountAlias 注册为 FPaths 根别名。Content/Materials/M_Metal.material → /Game/Materials/M_Metal (Material)
const FAssetData* Find(const FAssetPath&)按逻辑路径查询；无则 nullptr
std::filesystem::path Resolve(const FAssetPath&)逻辑路径 → 物理文件（经 FPaths 根别名）
std::optional<std::vector<std::uint8_t>> Load(const FAssetPath&)读资产原始字节；缺失/不可读回 nullopt
std::size_t GetAssetCount()已登记资产数
