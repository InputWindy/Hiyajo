Timer — API

计时分析 + 游戏时钟——两个单例：FTimer（分层作用域计时）+ FGameClock（带时间缩放/暂停的实时/游戏时钟，惰性推进、无需每帧 Tick）。Get() 都定义在 Timer.dll。纯 std（std::chrono）。

FTimer — 分层作用域计时

FTimerclass : TSingleton<FTimer>, IPlugin<IInit, IShutdown>

栈式作用域计时器——内部 FNode 树（Root → Children map，同名节点累加）。BeginScope 下推、EndScope 上弹并累计（Total/Max/Count），DumpToString 输出毫秒缩进文本树。

签名说明
static FTimer& Get()进程唯一访问器——定义在 Timer.cpp
void Initialize(int, char**) overrideReset 计时树
void Shutdown() overrideReset 计时树
void BeginScope(std::string_view Name)下推作用域（须与 EndScope / FScopedTimer 配对）
void EndScope()弹当前作用域并累计耗时（不平衡时忽略）
void Reset()清空全部累计
std::string DumpToString()毫秒格式文本树（total/calls/avg/max）

FScopedTimerclass（RAII）

RAII 作用域计时——构造 BeginScope、析构 EndScope（禁拷贝）。

签名说明
explicit FScopedTimer(std::string_view Name)构造即 BeginScope
~FScopedTimer()析构即 EndScope

FGameClock — 游戏时钟

FGameClockclass : TSingleton<FGameClock>, IPlugin<IInit, IShutdown>

实时/游戏时钟，带时间缩放与暂停。惰性推进：GetGameSeconds() 调用时累计「距上次调用的墙钟差 × TimeScale」，无需每帧 Tick；暂停时冻结。

签名说明
static FGameClock& Get()进程唯一访问器——定义在 Timer.cpp
void Initialize(int, char**) override无操作
void Shutdown() override无操作
double GetRealSeconds()自构造起的墙钟秒数
double GetGameSeconds()游戏秒数（缩放 × 暂停冻结；惰性推进）
double GetDeltaSeconds()上次推进的游戏时间差（秒）
void SetTimeScale(double)设置时间缩放
void SetPaused(bool)暂停/恢复（暂停前先推进一次）
double GetTimeScale()当前时间缩放
bool IsPaused()是否暂停
