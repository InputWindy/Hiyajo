Resource — API

类型化异步资源系统单例服务——专用 IO 线程（FThreadedServer）做异步导入/导出，目录以 FName 为 key，虚拟路径经 FPaths 解析。Get() 定义在 Resource.dll。依赖插件：Name、Paths。内部实现类型（FTransferState / FBulkData / FTransferHandle）只前向声明、完全隐藏。

配置基类

FImportConfigstruct

导入配置——虚拟源路径，经 FPaths 解析。资产路径（目录 key）由去掉扩展名推导。

成员说明
std::string SourcePath虚拟源路径，如 "Raw/mesh.fbx"（目录 key = 去掉扩展名）

FExportConfigstruct

导出配置——物理目标路径，直接写盘。

成员说明
std::string DestinationPath显式物理路径，如 "C:/Out/mesh.fbx"

FResource — 资源基类

FResourceclass

类型化资源基类——所有具体资源类型（如 FMesh）派生自它，持资产路径。

签名说明
virtual ~FResource()虚析构
explicit FResource(std::string Path)持路径构造
std::string_view GetPath()资产路径

导入器 / 导出器

TResourceImporter<TResource>struct（用户特化）

导入器——默认未定义，按资源类型特化。特化须提供 using FConfig + static bool Import(const FConfig&, std::span<const std::uint8_t>, TResource&)，只解码原始字节。

签名说明
using FConfig = ...导入配置类型
static bool Import(const FConfig&, std::span<const std::uint8_t>, TResource&)解码字节 → 资源；成功返回 true

TResourceExporter<TResource>struct（用户特化）

导出器——默认未定义，按资源类型特化。特化须提供 using FConfig + static bool Export(const FConfig&, const TResource&, std::vector<std::uint8_t>&)，只编码原始字节。

签名说明
using FConfig = ...导出配置类型
static bool Export(const FConfig&, const TResource&, std::vector<std::uint8_t>&)编码资源 → 字节；成功返回 true

FResourceSystem — 异步传输服务器

FResourceSystemclass : TSingleton, FThreadedServer, IPlugin<IInit, IShutdown>

异步传输服务器 + 类型化导入/导出。导入：IO 线程读原始字节 → Tick（游戏线程）解码 → 入目录 → OnDone。导出：编码在调用方线程（同步读目录资源），仅磁盘写入交给 IO 线程，OnDone(bool) 在游戏线程（经 Tick）。

签名说明
static FResourceSystem& Get()进程唯一访问器——定义在 Resource.cpp
~FResourceSystem()虚析构（FImpl 完整处释放）
void Initialize(int, char**) override启动 IO 线程（FThreadedServer::Initialize）
void Shutdown() override停 IO 线程 + join，清空 pending 与目录
void Tick()游戏线程每帧调用——应用就绪传输（每帧至多 1 个导入）
template<TResource> bool Import(FConfig, OnDone = {})异步导入；OnDone(const FResource*) 收注册资源或 nullptr
template<TResource> bool Export(FConfig, AssetPath, OnDone = {})异步导出；调用方须保证资源在导出期间存活且不变
const FResource* Find(std::string_view AssetPath)查已加载资源；无则 nullptr
const FResource* TryLoad(std::string_view AssetPath)尝试加载：即 Find

内部（protected，模板实现用）

签名说明
bool EnqueueImport(SourcePath, AssetPath, OnBulkReady)IO 线程读文件 → 就绪回调
bool EnqueueExport(Bytes, DestinationPath, OnDone)编码已完成（调用方线程）→ IO 线程写盘
const FResource* RegisterResource(AssetPath, unique_ptr<FResource>)入目录（FName key）
void ProcessReadyIO()轮询就绪传输并在游戏线程应用
