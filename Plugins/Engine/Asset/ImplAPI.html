void FAssetRegistry::Scan(const std::filesystem::path& ContentDir, std::string_view MountAlias)

← 公开 API · void

递归扫描内容目录：目录不存在直接返回；先把 MountAlias 映射为 FPaths root（虚拟路径走平台根抽象），再逐文件建 FAssetData（虚拟路径 = /Alias/相对路径去扩展名），按扩展名判定类型。

Scan(ContentDir, MountAlias): 1. if !is_directory(ContentDir): return 2. FPaths::Get().SetRoot(MountAlias, ContentDir) 3. lock(Mutex): 4. 递归遍历目录: 5. 跳过错误/非普通文件 6. Relative = 相对 ContentDir 的路径 7. if 无扩展名: continue 8. Data.Path = "/" + MountAlias + "/" + Relative(去扩展名) 9. Data.Type = TypeFromExtension(扩展名) 10. Assets[Path] = move(Data)

EAssetType TypeFromExtension(std::string_view Extension)

内部 · EAssetType

扩展名 → 资产类型映射：".material"→Material、".texture"→Texture，其余 Unknown。

TypeFromExtension(Ext): 1. if Ext == ".material": return Material 2. if Ext == ".texture": return Texture 3. return Unknown

const FAssetData* FAssetRegistry::Find(const FAssetPath& Path) const

← 公开 API · const FAssetData*

按虚拟路径查登记表（key 为路径字符串）；未命中返回 nullptr。持锁读。

Find(Path): 1. lock(Mutex): 2. It = Assets.find(Path.GetPath()) 3. return It != end ? &It->second : nullptr

std::filesystem::path FAssetRegistry::Resolve(const FAssetPath& Path) const

← 公开 API · std::filesystem::path

虚拟路径落盘：去掉前导 '/' 后交给 FPaths::Resolve（按 root 别名拆接物理路径）。

Resolve(Path): 1. P = Path.GetPath(); 去前导 '/' 2. return FPaths::Get().Resolve(P)

std::optional<std::vector<std::uint8_t>> FAssetRegistry::Load(const FAssetPath& Path) const

← 公开 API · std::optional<std::vector<std::uint8_t>>

先 Find 拿元数据；未登记或打不开文件返回 nullopt，否则 binary 流读全部字节。

Load(Path): 1. Data = Find(Path); if !Data: return nullopt 2. Stream = ifstream(Data.File, binary) 3. if !Stream: return nullopt 4. Bytes = 读全部字节 (istreambuf_iterator) 5. return Bytes

登记表条目数。持锁读。

GetAssetCount(): 1. lock(Mutex): return Assets.size()
