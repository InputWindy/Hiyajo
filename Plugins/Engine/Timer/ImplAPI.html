void FTimer::BeginScope(std::string_view Name)

← 公开 API · void

进入作用域：取当前节点下同名子节点（map 自动创建），记 start 时间，下潜。同名重复进入会累积到同一节点。

BeginScope(Name): 1. Child = Current->Children[Name] 2. Child.Name = Name 3. Child.Start = steady_clock::now() 4. Current = &Child

void FTimer::EndScope()

← 公开 API · void

退出作用域：已在 Root 则忽略（不平衡调用）；否则累计 elapsed 到 TotalSeconds、更新 MaxSeconds、Count++，回退到父节点。

EndScope(): 1. if Current == Root: return // 不平衡，忽略 2. Elapsed = now() - Current->Start 3. Current->TotalSeconds += Elapsed 4. Current->MaxSeconds = max(Max, Elapsed) 5. ++Current->Count 6. Current = Current->Parent

void FTimer::Reset()

← 公开 API · void

重建 Root 节点，游标回到根。

Reset(): 1. Root = FNode{"Root"} 2. Current = &Root

std::string FTimer::DumpToString() const

← 公开 API · std::string

递归格式化计时树为文本——每层缩进 2 空格，节点输出 总 ms / 调用次数 / 平均 ms / 最大 ms，再递归子节点。

DumpToString(): 1. 定义 Format(Node, Depth): 2. 缩进 + Node.Name + ": " 3. if Count > 0: 总ms (N 次调用, 平均 ms, 最大 ms) 4. 换行; for 子节点: Format(Child, Depth+1) 5. Format(Root, 0); return 结果字符串

double FGameClock::GetGameSeconds()

← 公开 API · double

惰性推进的游戏秒数：未暂停时按 (now - LastReal) × TimeScale 累加并记 DeltaSeconds；暂停期间只更新 LastReal 不推进。返回累计 GameSeconds。

GetGameSeconds(): 1. Now = steady_clock::now() 2. if !bPaused: 3. Delta = (Now - LastReal) * TimeScale 4. GameSeconds += Delta; DeltaSeconds = Delta 5. LastReal = Now 6. return GameSeconds

double FGameClock::GetDeltaSeconds()

← 公开 API · double

取上一帧游戏帧间隔——先触发一次 GetGameSeconds 推进再返回缓存值。

GetDeltaSeconds(): 1. GetGameSeconds() // 推进 2. return DeltaSeconds

void FGameClock::SetTimeScale(double InScale)

← 公开 API · void

void FGameClock::SetPaused(bool bInPaused)

← 公开 API · void

暂停/恢复：进入暂停瞬间先推进一次游戏时间（冻结前结算），再置标志。

SetPaused(bInPaused): 1. if bInPaused and !bPaused: 2. GetGameSeconds() // 冻结前推进 3. bPaused = bInPaused
