Platform — API

原生表面单例服务——给 RHI 提供原生窗口/上下文句柄：桌面端（Win32/Linux）经 GLFW 窗口，Linux 可走 EGL pbuffer 无头上下文。Get() 定义在 Platform.dll。无头构建开关 -DMAHO_HEADLESS=ON 不拉 GLFW。依赖插件：无。内部 backend（FGlfwWindow / FEGLHeadlessWindow / FPlatformBackend）全在 cpp 匿名命名空间，头文件只暴露 IPlatform 抽象。

原生表面

FNativeSurfaceusing 别名

原生表面句柄——不透明指针，具体含义随平台：GLFWwindow*（桌面窗口）/ EGLContext（Linux 无头）/ ANativeWindow*（Android）/ UIView*（iOS）……

类型说明
void* FNativeSurface不透明原生句柄；无头或创建失败为 nullptr

IPlatformclass（接口）

最小平台接口——只暴露原生表面给 RHI。不是所有平台都有"窗口"（headless / Android surface / iOS view），窗口语义隐藏在这个单访问器后面。

签名说明
virtual ~IPlatform() = default虚析构
[[nodiscard]] virtual FNativeSurface GetNativeWindow() const = 0原生窗口/表面句柄；无头或创建失败为 nullptr

FPlatformSystem — 表面服务

FPlatformSystemclass : TSingleton, IPlugin<IInit, IShutdown>

平台系统——原生表面 + 事件（TSingleton 服务）。backend 由 CreateWindow / CreateHeadlessContext 惰性创建；事件经 PollEvents() 显式泵送（无隐式 stage 循环）。宿主驱动固定生命周期：Initialize() → 建表面 → 主循环 → Shutdown()。

签名说明
static FPlatformSystem& Get()进程唯一访问器——定义在 Platform.cpp
void Initialize(int, char**) override空启动——backend 惰性创建
void Shutdown() override销毁 backend（= DestroyWindow）
bool CreateWindow(int Width, int Height, std::string_view Title)建窗口（按平台选 backend，桌面 GLFW）；成功返回 true
bool CreateHeadlessContext(int Width, int Height)无头渲染上下文（Linux EGL pbuffer + OpenGL ES 2.0）
void DestroyWindow()销毁 backend（切换到无头）
void PollEvents()泵平台事件（每帧一次）；无 backend 为空操作
[[nodiscard]] FNativeSurface GetNativeWindow() const原生句柄；无头或失败 nullptr
[[nodiscard]] bool IsHeadless() constSurface == nullptr（inline）
[[nodiscard]] bool ShouldClose() const窗口关闭请求；无头或无事件恒 false
