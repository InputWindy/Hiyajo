Platform（Private）— 实现算法字典

cpp 侧每个函数的算法伪代码解释。公开 API 文档经 API.html 跳转落到这里。backend 选择：桌面（Win32/Linux）→ FGlfwWindow（GLFW 窗口）；Linux → FEGLHeadlessWindow（EGL pbuffer 无头）。FPlatformBackend 是 cpp 内聚合（Surface + PollEvents + ShouldClose 闭包），经 CreateWindowBackend / CreateHeadlessBackend 工厂产出。

生命周期

FPlatformSystem::Get()

← 公开 API · FPlatformSystem&

进程唯一访问器——Meyers 单例，static 局部在 Platform.dll 内，跨 DLL dllimport 解析到同一实例。

Get(): 1. static Instance 2. return Instance

FPlatformSystem::Initialize(int Argc, char** Argv)

← 公开 API · void

空启动——忽略参数。backend 不在这里创建，由 CreateWindow / CreateHeadlessContext 惰性创建。

Initialize(Argc, Argv): 1. (void)Argc; (void)Argv 2. // backend 惰性创建于 CreateWindow / CreateHeadlessContext

FPlatformSystem::Shutdown()

← 公开 API · void

直接委托 DestroyWindow——销毁 backend 表面 + 清空事件闭包。

Shutdown(): 1. DestroyWindow()

表面管理

FPlatformSystem::CreateWindow(Width, Height, Title)

← 公开 API · bool

先销毁旧 backend，再经工厂建 GLFW 窗口 backend，迁移三件套（表面 + 两个闭包）。成功 = 表面非空且原生句柄非空。

CreateWindow(Width, Height, Title): 1. DestroyWindow() 2. Backend = CreateWindowBackend(Width, Height, Title) 3. Surface = move(Backend.Surface) 4. PollEventsFn = move(Backend.PollEvents) 5. QueryShouldClose = move(Backend.ShouldClose) 6. return Surface && Surface->GetNativeWindow() != nullptr

FPlatformSystem::CreateHeadlessContext(Width, Height)

← 公开 API · bool

先销毁旧 backend，再经工厂建 EGL 无头 backend（Linux）。非 Linux 返回空 backend → false。

CreateHeadlessContext(Width, Height): 1. DestroyWindow() 2. Backend = CreateHeadlessBackend(Width, Height) 3. Surface / PollEventsFn / QueryShouldClose = move(...) 4. return Surface && Surface->GetNativeWindow() != nullptr

FPlatformSystem::DestroyWindow()

← 公开 API · void

销毁 backend（unique_ptr reset → 触发 FGlfwWindow / FEGLHeadlessWindow 析构），清空闭包——系统回到无头态。

DestroyWindow(): 1. Surface.reset() 2. PollEventsFn = {} 3. QueryShouldClose = {}

FPlatformSystem::PollEvents()

← 公开 API · void

有 backend 则调事件泵闭包（GLFW：glfwPollEvents）；无 backend（无头）为空操作。

PollEvents(): 1. if PollEventsFn: PollEventsFn()

FPlatformSystem::GetNativeWindow() const

← 公开 API · FNativeSurface

转发给当前 backend；无 backend 返回 nullptr。

GetNativeWindow(): 1. return Surface ? Surface->GetNativeWindow() : nullptr

FPlatformSystem::ShouldClose() const

← 公开 API · bool

有关闭查询闭包则调（GLFW：glfwWindowShouldClose）；无 backend / 无头恒 false。

ShouldClose(): 1. return QueryShouldClose && QueryShouldClose()

Backend 工厂（cpp 匿名命名空间）

CreateWindowBackend(Width, Height, Title)

内部 · FPlatformBackend

桌面（非无头构建且 Win32/Linux）→ 建 FGlfwWindow，闭包捕获裸指针（backend 由 FPlatformSystem 持有，生命周期安全）。无头构建 / 其他平台 → 返回空 backend。

CreateWindowBackend(Width, Height, Title): 1. #if !MAHO_HEADLESS && (_WIN32 || __linux__) 2. Backend = make_unique<FGlfwWindow>(Width, Height, Title) 3. Raw = Backend.get() 4. return { move(Backend), 5. [Raw]() { Raw->PollEvents(); }, 6. [Raw]() { return Raw->ShouldClose(); } } 7. #else 8. return {} // 无头构建：无窗口 backend 9. #endif

CreateHeadlessBackend(Width, Height)

内部 · FPlatformBackend

Linux → 建 EGL 无头 backend（无事件闭包，headless 无窗口事件）；其他平台返回空。

CreateHeadlessBackend(Width, Height): 1. #if __linux__ 2. Backend = make_unique<FEGLHeadlessWindow>(Width, Height) 3. return { move(Backend), {}, {} } 4. #else 5. return {} // 非 Linux 不支持无头 6. #endif

GLFW backend — FGlfwWindow（桌面窗口）

FGlfwWindow::FGlfwWindow(Width, Height, Title)

内部 · void

glfwInit 后建窗口；失败时 Window 保持 nullptr（创建失败可检测）。

FGlfwWindow(Width, Height, Title): 1. if glfwInit(): 2. Window = glfwCreateWindow(Width, Height, Title) 3. // 失败: Window = nullptr

FGlfwWindow::~FGlfwWindow()

内部 · void

销毁窗口 + glfwTerminate。注意 #undef CreateWindow（Windows.h 宏污染）在头文件与 cpp 顶部各一次。

~FGlfwWindow(): 1. if Window: glfwDestroyWindow(Window) 2. glfwTerminate()

FGlfwWindow::PollEvents()

内部 · void

转发 glfwPollEvents——处理窗口事件（关闭请求、输入等）。

PollEvents(): 1. glfwPollEvents()

FGlfwWindow::ShouldClose() const

内部 · bool

窗口存在且收到关闭请求才返回 true。

ShouldClose(): 1. return Window != nullptr && glfwWindowShouldClose(Window)

EGL backend — FEGLHeadlessWindow（Linux 无头）

FEGLHeadlessWindow::FEGLHeadlessWindow(Width, Height)

内部 · void

Surfaceless EGL 平台 + pbuffer 表面 + OpenGL ES 2.0 上下文：取 Display → 初始化 → 选配置（PBUFFER + ES2）→ 建 pbuffer 表面 → 建上下文 → eglMakeCurrent。任一步失败即 return（成员保持 EGL_NO_*）。

FEGLHeadlessWindow(Width, Height): 1. Display = eglGetPlatformDisplay(EGL_PLATFORM_SURFACELESS_MESA, EGL_DEFAULT_DISPLAY) 2. if Display == EGL_NO_DISPLAY || !eglInitialize: return 3. eglBindAPI(EGL_OPENGL_ES_API) 4. eglChooseConfig(PBUFFER_BIT + OPENGL_ES2_BIT) → Config; 失败 return 5. Surface = eglCreatePbufferSurface(Display, Config, {W, H}) 6. if Surface == EGL_NO_SURFACE: return 7. Context = eglCreateContext(Display, Config, ES2) 8. if Context == EGL_NO_CONTEXT: return 9. eglMakeCurrent(Display, Surface, Surface, Context)

FEGLHeadlessWindow::~FEGLHeadlessWindow()

内部 · void

逆序释放：先 MakeCurrent 摘除 → 毁上下文 → 毁表面 → eglTerminate。

~FEGLHeadlessWindow(): 1. eglMakeCurrent(Display, EGL_NO_SURFACE, EGL_NO_SURFACE, EGL_NO_CONTEXT) 2. if Context != EGL_NO_CONTEXT: eglDestroyContext(Display, Context) 3. if Surface != EGL_NO_SURFACE: eglDestroySurface(Display, Surface) 4. eglTerminate(Display)
