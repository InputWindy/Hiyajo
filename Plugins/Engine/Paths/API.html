Paths — API

路径解析单例服务——根别名（如 Engine）→ 物理路径。Resolve 把 "Alias/Sub/Path"（或 "Alias:Sub/Path"）解析为物理路径。Get() 定义在 Paths.dll。纯 std。

FPaths — 路径解析单例

FPathsclass : TSingleton<FPaths>, IPlugin<IInit, IShutdown>

根别名注册表——内部 std::map<std::string, std::filesystem::path> Roots。引擎内一切跨平台路径抽象（Asset MountAlias、Resource 虚拟源路径）经它落地。

签名说明
static FPaths& Get()进程唯一访问器——定义在 Paths.cpp（Paths.dll）
void Initialize(int, char**) override清 Roots
void Shutdown() override清 Roots
void SetRoot(std::string_view Alias, std::filesystem::path)注册/覆盖根别名（如 "Engine" → 引擎目录）
std::filesystem::path Resolve(std::string_view VirtualPath)解析 "Alias/Sub/Path"（或 "Alias:Sub/Path"）；别名未注册时原样返回
bool HasRoot(std::string_view Alias)别名是否已注册
