std::filesystem::path FPaths::Resolve(std::string_view VirtualPath) const

← 公开 API · std::filesystem::path

虚拟路径解析：找第一个 '/' 或 ':' 作为分隔——无分隔则整个当作别名（命中返回根，否则原样当物理路径）；有分隔则 Alias 前缀查 Roots，未命中原样返回，命中则 根 / 剩余段 拼接。

Resolve(VirtualPath): 1. Sep = find_first_of("/:") 2. if Sep == npos: // 纯别名 3. It = Roots.find(VirtualPath) 4. return 命中 ? It->second : path(VirtualPath) 5. Alias = VirtualPath[0..Sep) 6. It = Roots.find(Alias) 7. if 未命中: return path(VirtualPath) 8. return It->second / VirtualPath[Sep+1..]
