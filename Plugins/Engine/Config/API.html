Config — API

INI 风格配置单例服务（UE DefaultEngine.ini 格式）——Load 解析 INI，按 Section/Key 读值，运行时 SetString 覆盖。Get() 定义在 Config.dll。纯 std。

FConfig — INI 配置单例

FConfigclass : TSingleton<FConfig>, IPlugin<IInit, IShutdown>

两级配置表：std::map<std::string, FSection>（FSection = std::map<std::string, std::string>）。[Section] 行切段、Key = Value 行入库；; / # 注释。

签名说明
static FConfig& Get()进程唯一访问器——定义在 Config.cpp（Config.dll）
void Initialize(int, char**) override清 Sections
void Shutdown() override清 Sections
bool Load(std::string_view Path)解析 INI 文件；文件打不开返回 false
std::optional<std::string> GetString(Section, Key)读字符串（无则 nullopt）
std::int64_t GetInt(Section, Key, Default = 0)读整数（解析失败回默认）
double GetFloat(Section, Key, Default = 0.0)读浮点（解析失败回默认）
bool GetBool(Section, Key, Default = false)读布尔（true/1/yes/on，大小写不敏感）
void SetString(Section, Key, std::string)运行时覆盖值
bool HasSection(Section)段是否存在
bool HasKey(Section, Key)键是否存在
