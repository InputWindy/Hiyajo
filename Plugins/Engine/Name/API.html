Name — API

字符串驻留标识——不可变 FName（interned，O(1) 比较）+ 全局驻留池 FNamePool（单例服务，Get() 定义在 Name.dll）。纯 std，零三方。

FName — 不可变标识符

FNameclass

Interned 不可变字符串标识——构造时把字符串 intern 进全局池，相同字符串共享同一条目，比较按内部 Id（O(1)）。默认构造 = None（空，Id == 0）。

签名说明
FName()默认构造 = None（空）
explicit FName(std::string_view)intern 字符串（经 FNamePool::Get().Intern）
std::string_view ToString()反查池内字符串（StringForId）
bool IsNone()是否为 None（Id == 0）
std::uint32_t GetId()池内数字 Id
operator== / != / <按 Id 比较（O(1)）

FNamePool — 全局驻留池

FNamePoolclass : TSingleton<FNamePool>, IPlugin<IInit, IShutdown>

全局 interned 字符串池（Mutex 保护，线程安全）。Intern 幂等——已存在的字符串返回既有条目，不重复存储。

签名说明
static FNamePool& Get()进程唯一访问器——定义在 Name.cpp（Name.dll）
void Initialize(int, char**) override清池（free）
void Shutdown() override清池（free）
FName Intern(std::string_view)驻留字符串——返回规范 FName（线程安全）
std::string_view StringForId(std::uint32_t)Id 反查字符串（Intern 的逆）

std::hash 特化

std::hash<Maho::Name::FName>struct 特化

签名说明
std::size_t operator()(FName) noexcept哈希值 = hash<uint32_t>(GetId())
