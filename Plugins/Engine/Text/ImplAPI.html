std::string MakeKey(std::string_view InNamespace, std::string_view InKey, std::string_view InCulture)

内部 · std::string

三段拼接目录 key——中间以单元分隔符 \x1f 隔开，杜绝 "a"+"bc" == "ab"+"c" 式碰撞。

MakeKey(Ns, Key, Culture): 1. 预留 Ns + Key + Culture 长度 + 2 2. 追加 Ns; 追加 '\x1f'; 追加 Key; 追加 '\x1f'; 追加 Culture 3. return

void FTextManager::LoadTranslationsFromJson(std::string_view JsonText)

← 公开 API · void

nlohmann 解析 JSON 数组，逐条取 Namespace/Key/Culture/Text 四字段转 AddTranslation。单次持锁（逐条锁亦可，此处复用 AddTranslation 内锁）。

LoadTranslationsFromJson(JsonText): 1. Root = json::parse(JsonText) 2. for Entry in Root: 3. AddTranslation(Entry["Namespace"], Entry["Key"], 4. Entry["Culture"], Entry["Text"])

const std::string* FTextManager::FindTranslation(std::string_view InNamespace, std::string_view InKey, std::string_view InCulture) const

← 公开 API · const std::string*

按三段 key 查目录——未命中返回 nullptr。持锁读。

FindTranslation(Ns, Key, Culture): 1. lock(Mutex): 2. It = Catalog.find(MakeKey(Ns, Key, Culture)) 3. return It != end ? &It->second : nullptr
