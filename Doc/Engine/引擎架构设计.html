1. 总览

flowchart TB
  EP["EntryPoint main"] --> CA["CreateApplication"]
  CA --> GameApp["FMyGameApp : FAppBase"]
  EP --> Run["FAppBase.Run 唯一生命周期入口"]
  Run --> Boot["Initialize"]
  Run --> Loop["RunMainLoop"]
  Run --> Shut["Shutdown"]

  Boot --> Cfg["Configure + Ini + Log"]
  Boot --> StagesInit["PreInit / Init / PostInit"]
  Boot --> PostInitHook["PostInitialize PushLayer"]

  Loop --> TickStages["每帧 ExecuteStage 族"]
  Shut --> ClearL["ClearLayers"]
  Shut --> StagesShut["PrepareExit (WaitForExit) / Shutdown"]
组件职责不负责
FAppBase stage 调度、RegisterModule / GetModule<T>、Layer 寿命与 Post 绑定 子系统业务语义；不再持有 Render/GC 等特化成员
IModule 扩展固定 EModuleStage 本体（引擎 / 未来插件） 游戏 World / Editor 内容
FLayer stage 结束后的可编程逻辑（绑到 Post 多播） 替换 Module；不是独立调度器
FConfig 路径、窗口、清屏色等配置 运行时子系统实例
对外生命周期只暴露 void Run()。Initialize / Shutdown / ExecuteStage 均为 private。 游戏通过 Configure / PostInitialize / PreShutdown（protected）与 PushLayer 接入，不 override Tick 虚钩。 已删除 FLayerStack：栈语义由 FAppBase::LayerBindings + Post 绑定顺序承担。

2. 双轨扩展：Module vs Layer

ModuleLayer

驱动ExecuteStage 按 DAG 直接调用注册时 AddRaw 到 PostStageDelegates，由 Broadcast 带动

ExecuteStage 契约（无 Pre 多播）

flowchart LR
  S["EModuleStage S"] --> M["Modules.OnStage 按 Startup/Shutdown 序"]
  M --> P["PostStageDelegates Broadcast"]
  P --> L["已绑定的 Layer.On* / 工具回调"]
  • 相邻 stage 之间：上一 stage 的 Post ≈ 下一 stage 开始前的空隙；再设 Pre 多播语义重复，故只保留 Post。
  • Init 族：任一 Module 返回 false 则中止启动。
  • Shutdown 族：Module 使用 逆序（ShutdownOrder）。

3. 生命周期时序

sequenceDiagram
  participant Main as EntryPoint
  participant App as FAppBase
  participant Mods as EngineModules
  participant Game as FMyGameApp
  participant Lay as Layers

  Main->>App: CreateApplication / Run
  App->>Game: Configure(Config)
  App->>Game: RegisterModules
  Note over App: Load DefaultEngine.ini CVars + FLog + Timer
  App->>Mods: RebuildModuleOrder DAG
  App->>Mods: ExecuteStage PreInit
  App->>Mods: ExecuteStage Init
  App->>Mods: ExecuteStage PostInit
  App->>Game: PostInitialize
  Game->>App: PushLayer / PushOverlay（含 FScriptLayer）
  App->>Lay: Attach + Bind PostStageDelegates
  App->>Mods: AttachModules
  loop while bRunning
    App->>Mods: Tick ExecuteStages
    Mods-->>Lay: Post Broadcast OnUpdate 等
  end
  App->>Game: PreShutdown
  App->>Lay: Detach + Clear
  App->>Mods: DetachModules + Shutdown stages
EntryPoint 仍只调 App->Run()，不拆 Initialize/Shutdown。 FAppBase 是空流水线：默认 Module / Layer 由游戏 RegisterModules / PostInitialize 组装（可调用 RegisterEngineModules）。

4. 默认 Module DAG

flowchart TB
  Eng["Engine"] --> Plat["Platform"]
  Plat --> Rend["Render"]
  Rend --> ImGui["ImGui"]
  Plat --> ImGui
  ImGui --> GC["GC"]
  GC --> Res["Resource"]
  Res --> Work["Worker"]
Module依赖Init 要点Tick / 其它 stage
FEngineModule—FEngine::InitializeUpdate：Engine.Tick
FPlatformSystemModuleEngine创建 Window / HeadlessBeginFrame：PollEvents；EndFrame：headless 自动退出
FRenderSystemModulePlatformRenderServer + RHIBeginFrame：Resize；PostRender：无 ImGui 时 clear/present/flush
FImGuiModuleRender, Platform有 OS 窗体才 InitBeginFrame NewFrame；ProcessInput Escape；PostRender EndFrame+Present+Flush
FGCSystemModuleImGuiGCManager::InitializeUpdate：GCManager.Tick
FResourceSystemModuleGCResourceManager::Initialize(GC)；订阅 App.GetScriptSystem().OnLuaReady—
FWorkerModuleResourceWorkerPool::Initialize—

Lua 不在 Module DAG：游戏 Push FScriptLayer；FScriptSystem 与 FLog / FConsole / FTimer 同级由 FAppBase 托管，经 GApp / GetScriptSystem() 访问。默认引擎 Module 用 RegisterEngineModules(*this) 由游戏主动拉取。

  • 访问：App.GetModule<FRenderSystemModule>()->GetServer()，无 GetRenderServer 等特化 getter。
  • 拓扑并列节点按 注册顺序 出队，保证启动序稳定。

5. 单帧管线时序

sequenceDiagram
  participant App as FAppBase
  participant Plat as Platform
  participant ImGui as ImGui
  participant GC as GC
  participant Eng as Engine
  participant Post as PostDelegates
  participant Lay as Layers

  App->>Plat: BeginFrame PollEvents
  App->>ImGui: BeginFrame NewFrame
  App->>Post: Broadcast BeginFrame
  Post->>Lay: OnBeginFrame

  App->>ImGui: ProcessInput Escape
  App->>Post: Broadcast ProcessInput
  Note over Post,Lay: Overlay 先于 Layer
  Post->>Lay: OnProcessInput

  loop FixedUpdate accumulator
    App->>Post: Broadcast FixedUpdate
    Post->>Lay: OnFixedUpdate（含 FScriptLayer → Lua）
  end

  App->>Eng: Update Engine.Tick
  App->>GC: Update GC.Tick
  App->>Post: Broadcast Update
  Post->>Lay: OnUpdate World/Editor/Script

  App->>Post: Broadcast LateUpdate / PreRender / Render
  Post->>Lay: OnLateUpdate / OnPreRender / OnRender

  App->>ImGui: PostRender EndFrame Present Flush
  App->>Post: Broadcast PostRender
  Post->>Lay: OnPostRender

  App->>Plat: EndFrame headless auto-exit
  App->>Post: Broadcast EndFrame
  Post->>Lay: OnEndFrame
上图省略了未参与该 stage 的 Module。要点：同一 stage 内永远是 全部 Module 先跑完，再 Post 广播（含 FScriptLayer）。 ImGui EndFrame 与 Present 放在 PostRender 的 Module 侧，因此晚于 Layer 的 OnRender（以及 Update 里画的 ImGui Demo）。

6. Layer 注册与绑定

sequenceDiagram
  participant Game as FMyGameApp
  participant App as FAppBase
  participant L as FWorldLayer
  participant D as PostStageDelegates

  Game->>App: PushLayer(WorldLayer)
  App->>L: OnAttach
  App->>App: 插入 Layer 段 LayerInsertIndex
  App->>App: RebuildLayerPostBindings
  loop 每个 Tick stage 钩子
    App->>D: AddRaw Layer.OnUpdate 等
  end
  Note over App,D: ProcessInput 按栈逆序绑定 Overlay 优先
  Game->>App: PushOverlay(EditorLayer)
  App->>App: 尾插 Overlay 段并 Rebuild
  • PushLayer：插在 Layer 段末尾（分界 LayerInsertIndex 前）。
  • PushOverlay：全栈尾插（Overlay 段）。
  • Update / Render 等：Broadcast 正向 = Layer 再 Overlay。
  • ProcessInput：绑定按栈逆序 = Overlay 先处理输入。
  • OnAttach / OnDetach 是入栈/出栈生命周期，不是 EModuleStage。

GC 保活

flowchart LR
  Ref["FObjectRef RefCount大于0"] --> Keep["保活"]
  Persist["Persistent Package Object"] -->|"不进 Transient 回收"| Keep
  Scan["扫 LiveObjects"] -->|"RefCount等于0"| Pending["PendingKill 约30s Purge"]
  • 保活：仅 RefCount>0（catalog / Outer / 业务 FObjectRef）；无 RootSet、无引用图 Mark。互持 FObjectRef 会泄漏 — 一侧用裸指针观察，需要时再 Wrap。
  • 默认 Tick：Collect 约 1s；Purge Pending 约 30s（CVar 可调）。
  • Package / CreateResource 同步；raw 填充异步；Flush(Resource) 只等该资源 raw。

8. Package 跨包依赖

  • 跨包引用：成员用 FObjectRef；Save 时 GetReferencedObjects，Load 时 SetReferencedObjects + FObjectRef::Wrap。
  • 软路径：PackageName.ObjectName；JSON：objects[].refs，包级 dependencies[{name,file}]。
  • LoadPackage 先递归依赖包再创建本包对象；SavePackage(..., bSaveDependencies=true) 先递归存依赖。
  • GC 不读这套序列化引用图；存活仍只看 Root / RefCount。
