Public/Core/FrameGraph.h

FrameGraph —— 帧调度器 / 声明层 / 桥

三件强绑定的东西放在同一个头里：节点调度器 FFrameGraph、声明层 FFrameExtension、把声明翻译成一批任务的 FFrameBridge。

宏 MAHO_FRAMES_IN_FLIGHT : 3

环深度：同时在飞的帧槽数。相位就是 [0, K) 的环索引。

结构体 FTaskKey

节点实例的身份三元组。依赖就是指向目标实例的身份。

字段

public std::string_view Name

稳定身份名（必须指向静态存储，即字符串字面量）

public std::type_index Stage

阶段类型

public std::int32_t Phase

相位 = 环索引，不是绝对帧号

接口

public bool operator==(const FTaskKey& Other) const

精确比较（注册表用精确键）

类 FFrameGraph : FThreadedServer

节点调度器。全部图状态只被调度线程触碰，所以没有图锁，且该线程绝不阻塞。

字段

private std::deque<FTaskNode> Nodes

节点表，下标即 FNodeId（deque：元素含 atomic，不可移动）

private std::unordered_map<FTaskKey, FNodeId, FTaskKeyHash> Registry

身份 → 节点下标

private std::array<std::atomic<std::uint32_t>, kPhaseCount> SlotInFlight

每相位在飞计数：准入与 Wait 的依据

private std::atomic<std::uint32_t> AwaitingCompletion

待完成节点数（提交栅栏的计数）

接口

public bool Submit(std::vector<FTask> Tasks, std::string* OutReason = nullptr)

提交一批任务：校验（批内重复身份 / 相位越界 / 成环）→ 准入（阻塞调用方，直到这批点名的相位排空）→ 入队。提交即合并，没有重建。

public void Wait()

提交栅栏：阻塞到「我提交过的都完成」。计数由调用方在入队前自增、调度线程完成时自减 —— 所以它不会漏掉自己的工作。
