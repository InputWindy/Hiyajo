Maho.h

Maho.h —— 引擎聚合头

插件只需 `#include <Maho.h>`，就同时拿到 Core 基建与引擎帧系统。它是**唯一的聚合点**（原先的 Core.h 已折进来：一个聚合头只被另一个聚合头包含，就是纯间接）。下面这张表就是它带进来的东西。

包含的模块

头文件功能
Core/TypeList.h编译期有序类型列表 `TTypeList` 及运算（拼接 / 成员判断 / 保序去重并集）
Core/Delegate.h多播事件 `TMulticastEvent`：bind / broadcast / unbind，线程安全，无 DLL 边界
Core/Singleton.hCRTP 单例标识基类 `TSingleton`：纯标记，不强制生命周期
Core/Interface.h能力组合器 `IPlugin` / 有序阶段序列 `IPipeline`
Core/FrameGraph.h帧调度器 `FFrameGraph` + 声明层 `FFrameExtension` + 桥 `FFrameBridge`
Core/ThreadPool.h固定规模线程池 `FThreadPool`：`Submit` 入队即返，`Flush` 锁步屏障
Core/ThreadedServer.h常驻专用线程基类 `FThreadedServer`：单线程 + FIFO 串行队列
Core/Assembly.hDLL 加载原语 `FAssembly` + `ApplyModuleExtension`（平台后缀）
Core/Fatal.h致命 / 错误上报路径 + `MAHO_CHECK` / `MAHO_VERIFY` / `MAHO_ENSURE` 断言宏
Engine/Engine.h引擎侧：10 个 stage 能力接口 + `FEngineBase` + 引擎 stage 序列别名
（这个头还没有声明内容）
