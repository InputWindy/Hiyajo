类 FAssembly

One loaded module: the OS handle, the symbol lookup on it, and the shared plugin manifest. The manifest is the `PluginManager.json` the path layer resolves: it is read ONCE per process by `LoadManifest()`, and it is what `GetChildren` answers from -- the plugin tree the engine installs frames along. A module is loaded by its own object and unloaded when that object goes away (`~FAssembly`), so an assembly must outlive every symbol taken out of it.

Public/Engine/DerivedEdges.h

DerivedEdges.h

Deriving a frame graph's edges from RESOURCE ACCESS (`Engine/StageMetadata.h`), not from hand-written declarations. A stage declares what it touches (`MAHO_READ` / `MAHO_WRITE` / `MAHO_CREATE` / `MAHO_DESTROY`), and the resource it touches carries its own ordering semantics (`MAHO_DECLARE_RESOURCE_ORDERING`). This turns those two facts into the edges that were previously written by hand, one pair at a time, and discovered by crashing.

包含的头文件

头文件
`<Core/FrameGraph.h>`

类 FResourceEdgeDeriver : public IDerivedEdgeSource

The engine's edge deriver: aggregates one round's accesses BY RESOURCE and emits the pairs the resource's ordering semantics imply (see design D4/D5).

Note: It emits only OLDER-round -> this-round pairs, and never a same-round pair: inside one round every stage pair is already ordered by the frame's own stage chain, so a same-round edge would be redundant at best and a cycle at worst. `Snapshot` deliberately yields no Write -> Read edge at all (nothing can tear, and the edge would serialise the K-deep pipeline).
