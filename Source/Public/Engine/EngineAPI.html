Engine — API

匿名层 + 有序 stage 管线 + 任务图调度（header-only，Layer.h / Engine.h）。层只声明身份与逐 stage 依赖，全局调度由 FLayerTaskGraph 统一负责。

FLayerBase — 匿名锚点

FLayerBaseclass

所有层实例的多态锚点。层只闭合自己：稳定身份名（拓扑键）+ 逐 stage 依赖表。不管理依赖的生命周期——执行上下文完整性由 FLayerTaskGraph 保证。

签名说明
virtual ~FLayerBase()虚析构（跨 DLL 删除经 DLL 自己的代码）
virtual std::string_view GetName() const = 0稳定身份名——任务图的拓扑键
const FDependencyTable& GetDependencies() const逐 stage 依赖表
template<TMyStage, TDepObj, TDepStage> AddDependency()声明：this 在 TMyStage 依赖 TDepObj 在 TDepStage

嵌套类型

类型说明
FDependency { Name, Stage }依赖元组：dep 名 + dep 的 stage 接口 type_index
FDependencyTablemap<我的 stage type_index, vector<FDependency>>

FLayer — 装配语法糖

FLayer<TPipeline>class : FLayerBase, TPipeline

把 FLayerBase（身份 + 依赖）与 IPipeline（有序 stage）绑成一个层类型。二者无继承关系，调度时经 dynamic_cast 侧向转换。

用法说明
class FWorld : public FLayer<IPipeline<IMain, IShutdown>>== FLayerBase + IPipeline<IMain, IShutdown>

FLayerTaskGraph — 全局调度

FLayerTaskGraph<TPipeline, TContext = FEmptyContext>class : FTaskGraph

一组匿名 FLayer* → 编译 → 执行。契约：每个传入层实现同一 TPipeline。每层展开成每 stage 一个节点（自递进 + 跨对象依赖）。

签名说明
FLayerTaskGraph(FThreadPool&, TContext&)只绑定线程池 + 执行上下文（引用，不拷贝）
void Init(std::vector<FLayerBase*>)重建节点集（公开、可重复调用，每帧/重配）
bool Compile()接线 + 环/缺依赖检测
void Execute()异步拓扑分派（继承自 FTaskGraph）
void Flush()阻塞到排空（继承自 FTaskGraph）

引擎主循环（Engine.h）

IBeginFrame / ITick / IEndFrameclass

引擎主循环三阶段能力接口（各含一个无参纯虚方法）。

接口方法
IBeginFramevoid BeginFrame()
ITickvoid Tick()
IEndFramevoid EndFrame()

IEnginePipelineclass : IPipeline<IBeginFrame, ITick, IEndFrame>

引擎固定管线：BeginFrame → Tick → EndFrame。实现 Invoke<TStage>(TContext&) 的 if-constexpr 分派（stage → 方法调用）。

签名说明
template<TStage, TContext> Invoke(TContext&)stage → BeginFrame/Tick/EndFrame 分派

FEngineLayerclass : FLayer<IEnginePipeline>

引擎 feature 基类。业务 feature 继承它，实现三 stage 方法；跨 feature 依赖在构造函数里 AddDependency<ITick, FOther, IBeginFrame>()。

IEngineclass : IPlugin<IInit, IMain, IShutdown>

引擎锚点——生命周期能力 + 主循环。入口插件导出的唯一锚点，EntryPoint 经 FAssembly 查 "CreateEngine" 拿到 IEngine*。

签名说明
void Initialize(int, char**) 启动钩子（默认空）
int Main() final override主循环：Flush → 应用挂起变更 → Init → Compile → Execute
void Shutdown() override关闭钩子（默认空）
void Install(FEngineLayer*)安装语法糖（下帧生效）
void Uninstall(FEngineLayer*)卸载语法糖（下帧生效）

插件宏

MAHO_DECLARE_LAYER(LayerType)宏

在层类体内生成 StaticName() + GetName() 覆盖。名字取自类型名字符串化，依赖声明用同一类型推导，拓扑键自洽。

static constexpr std::string_view StaticName() { return "LayerType"; }
std::string_view GetName() const override { return StaticName(); }

MAHO_DECLARE_ENGINE(EngineType, DLL)宏

在引擎类体内展开 IEngine* 工厂 + 模块路径。入口插件的 extern "C" CreateEngine() bridge 转发到 CreateEngine()。

static Maho::IEngine* CreateEngine() { return new EngineType(); }
static std::string_view GetModulePath() { return DLL; }
