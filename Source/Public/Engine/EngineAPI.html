Engine — API

层体系（header-only，Layer.h）。Core 的类型无关基建（FQueue / FParallelScheduler / TQuery）在这里组装成"层"。所有跨 DLL 符号带 MAHO_API（单 vtable / RTTI 共享）。

命令类型

ELayerCommandenum class : uint64_t

层命令队列的 catalog 类别——FQueue 按它路由到 lane。

值说明
Install = 1安装子层命令的 lane
Uninstall = 2卸载子层命令的 lane

FInstallCommandstruct : ICommand

安装命令——携带要收养的子层实例，FlushCommands() 时经 Layers.push_back(Child) 应用。命令是纯数据载体（ICommand 仅 GetCatalogId()），执行是消费方（FLayer::FlushCommands）的职责。

成员说明
FLayerBase* Child待安装的子层实例
uint64_t GetCatalogId() override返回 ELayerCommand::Install

FUninstallCommandstruct : ICommand

卸载命令——携带要释放的子层实例，FlushCommands() 时 erase + delete 应用。

成员说明
FLayerBase* Child待卸载的子层实例
uint64_t GetCatalogId() override返回 ELayerCommand::Uninstall

FLayerBase — 组装基座

FLayerBaseclass : FQueue, FParallelScheduler

所有层实例的多态锚点（跨 DLL 单 vtable/RTTI，MAHO_API）。组装三个类型无关的 Core 基建：命令队列（FQueue）+ 并行执行（FParallelScheduler）+ 编译期查询（Query<TList>）。生命周期钩子（IInit/IShutdown）不在基类强制——能力经 IPlugin 可选组合。

签名说明
virtual ~FLayerBase()虚析构（跨 DLL 删除经 DLL 自己的代码）
template<T> bool Is() const运行时 dynamic_cast：此实例是否派生 T

继承能力（Core 基建）

来源说明
FQueue::Enqueue(unique_ptr<ICommand>)入队命令（任意线程，按 GetCatalogId 路由）
FQueue::Dequeue(catalogId)FIFO 取出某 lane 的命令
FParallelScheduler::ForEach(FCallables...)编译期变参并行 + barrier
FParallelScheduler::ForEach(Container, MakeTask)运行时容器并行

运行时分发

DispatchInstance自由函数模板

对单个 FLayerBase* 实例按候选类型列表 TTypeList 逐个 dynamic_cast，第一个匹配的类型交给 Visitor。用于层内类型筛选。

签名说明
void DispatchInstance(TTypeList<Ts...>, FLayerBase*, Visitor)按 TList 试 match，首中者 Visitor(T&)
void DispatchInstance<TList>(FLayerBase*, Visitor)便捷版（隐式 TList{}）

FLayer — 装配节点

FLayer<TRegisteredTypes...>class : FLayerBase

带编译期子层表的装配层。ctor 遍历子层类型表 Load 其 DLL 并安装；Install/Uninstall 经命令队列延迟到 FlushCommands()；ForEach<FLevels> 编译期分层序遍历（单例/实例双分支）。

签名说明
using FLayers = TTypeList<...>子层类型表
FLayer()遍历 FLayers，Load 每个 FModuleInstance 子层 → Enqueue Install → FlushCommands
~FLayer()只释放 Layers 实例内存（不静默 teardown）
template<T> Install()Load 子类型 → Enqueue Install 命令
Uninstall(FLayerBase*)Enqueue Uninstall 命令
virtual FlushCommands()安全点：Drain 队列——Install→Layers.push_back；Uninstall→erase+delete
constexpr Query()返回 TQuery<FLayers>（编译期筛选本层子层表）
template<FLevels, TVisitor> ForEach(Visitor)分层序遍历：单例表→T::Get()；实例表→DispatchInstance(Layers)

编译期特征（LayerDetail）

TIsSingleton / TLevelAllSingleton / TAllSingletonstruct

编译期检测"分层表是否为纯单例类型表"。TAllSingleton<FLevels>::value 驱动 ForEach 的 if-constexpr 分支。

签名说明
TIsSingleton<T>is_base_of<TSingleton<T>, T>
TLevelAllSingleton<FLevel>一层（TTypeList）全单例
TAllSingleton<FLevels>整棵分层表全单例

插件宏

static FLayerBase* CreateLayer() { return new CustomBase(); }
static std::string_view GetModulePath() { return AppDLL; }
