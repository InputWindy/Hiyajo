Core — API 文档

编译期 + 运行时基础设施。函数带 → 实现 的跳转到 Private 侧算法字典。

TypeList

TTypeList<TTypes...>struct

编译期有序类型列表。顺序即语义：TTypeList<A,B> ≠ TTypeList<B,A>。

成员变量

字段类型说明
Countconstexpr size_t类型个数

TCons / TAppend / TContainsstruct

列表操作：前插、后插、成员判断。

接口

签名说明
struct TCons<T, TList>前插
struct TAppend<TList, T>后插：TAppend_t
struct TContains<TList, T>成员判断：TContains_v

TTag / ForEach<TList>struct / function

运行时遍历列表：每个类型转成 TTag<T> 喂给 Visitor。Scheduler 满足 FForEachScheduler（有 Run(callables...)），决定串/并行。

接口

签名说明
TTag<T>::Type还原类型 T
void ForEach(Scheduler&&, Visitor&&, Args&&...)逐个类型调 Visitor(TTag<T>{}, args...)

Topology

TDependsOn<Key, TList>struct

一个依赖槽：在 Key 阶段，Self 依赖 TList 里的每个类型（依赖先完成，Self 后跑）。

成员变量

字段类型说明
Keyconstexpr auto阶段值
FDepsTList该阶段依赖的类型列表

TDependsPack<TSlots...>struct

多个 TDependsOn 槽的变参包。扩展声明 using FDependsPack = TDependsPack<...>。

接口

签名说明
static void ForEachSlot(Visitor)逐槽调 Visitor(Key, TList*)

Topo 排序算法namespace

编译期拓扑排序 / 分层 / 环检测 / 逆序。只吃每个节点的直接依赖，递归展开传递依赖。

接口

签名说明
Topo::TTopoSort_t<TNodes, Key>线性拓扑序
Topo::TLevels_t<TNodes, Key>按依赖层级分组
Topo::TIsAcyclic_v<TNodes, Key>环检测
Topo::TReverse_t<TList>反转列表

FDefaultSlot / FForwardTopology / FReverseTopology常量 / struct

FDefaultSlot = lambda 版 Execute 的默认排序 key（无 stage）。拓扑策略：正序 / 逆序。

Delegate

TDelegate<Ret(Args...)>class

单播委托：恰好一个绑定，可返回值。

接口

签名说明
void Bind(FFunction)绑定可调用对象
void BindRaw(Object*, Method)绑定成员函数
Ret Execute(Args...)调用
Ret ExecuteIfBound(Args...)调用，未绑定时返回默认值

TMulticastDelegate<Args...>class

多播委托：多个绑定，逐个广播。

接口

签名说明
FDelegateHandle Add(Fn)添加绑定
FDelegateHandle AddRaw(Object*, Method)添加成员绑定
void Broadcast(Args...)广播
void Remove(Handle)移除

Singleton / Scheduler

TSingleton<TDerived>class

CRTP Meyers 单例。与扩展体系平级——谁想单例谁继承。

接口

签名说明
static TDerived& Get()唯一实例（懒初始化，线程安全）

ISchedulerclass

调度器基类，声明 Run + 双 Execute 契约（= delete）。具体串/并行在 Engine/。

接口

签名说明
void Run(Callables...)驱动一组可调用（串/并行）
void Execute<Stage, TExtensions>()按 stage 分发（调 ExecuteStage(Stage)）
void Execute<TExtensions>(Visitor)按 lambda 分发（FDefaultSlot 排序）

Extension

TExtension<TDerived>class

单例扩展。只继承 TSingleton——不继承 ILayer；插件不需要动态加载，只有应用（宿主）显式继承 ILayer。

TExtensionList<TDerived, TExtensions...>class

单例 + 组装：同时是 TExtension（可驱动）和 TTypeList（一组扩展）。因为本身是 TExtension，可递归嵌套。

成员变量

字段类型说明
FExtensionsTTypeList<TExtensions...>这组扩展

Assembly

FAssemblyclass

动态加载原语：OS 模块句柄 + 符号探测。不认识插件/manifest/工厂，怎么解释符号是消费方的事。

接口

签名说明
bool Load(string_view Path) → 实现LoadLibrary / dlopen
void Unload() → 实现FreeLibrary / dlclose
void* GetProcAddress(const char*) → 实现符号探测
IsLoaded()是否已加载
T* GetProc<T>(const char*)类型化符号探测

ILayerinterface

已加载装配件的契约——有 Main 入口。DLL 导出 CreateExtension 返回它。

接口

签名说明
virtual int Main(int Argc, char** Argv) = 0装配件入口

Fatal

ReportFatal / InstallFatalHandlersfunction

致命路径 + 崩溃兜底（零依赖）。

接口

签名说明
void ReportFatal(const char*) → 实现输出致命信息并终止
void InstallFatalHandlers() → 实现装 std::terminate 兜底
