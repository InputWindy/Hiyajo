Assembly.cpp

FAssembly::Load(string_view Path)

← 公开 API · bool

把路径转成平台原生字符串，调用 OS 加载器。先卸掉旧句柄（幂等重载）。

Load(Path): 1. Unload() // 幂等：先释放旧句柄 2. Native = Path 转 std::string // LoadLibraryA 要 c 串 3. Windows: Handle = LoadLibraryA(Native) Posix: Handle = dlopen(Native, RTLD_NOW) 4. return Handle != nullptr // 加载失败返回 false

FAssembly::Unload()

← 公开 API · void

句柄为空直接返回；否则调 OS 卸载器并置空。重复调用安全。

Unload(): 1. if Handle == nullptr: return 2. Windows: FreeLibrary(Handle) Posix: dlclose(Handle) 3. Handle = nullptr

FAssembly::GetProcAddress(const char* Name)

← 公开 API · void*

按符号名查导出地址。未加载或查不到返回 nullptr。

GetProcAddress(Name): 1. if Handle == nullptr: return nullptr 2. Windows: return GetProcAddress(HMODULE(Handle), Name) Posix: return dlsym(Handle, Name)

Fatal.cpp

InstallFatalHandlers()

← 公开 API · void

装 std::terminate 兜底，进程入口最先调。互斥保护 + 幂等标记，重复调用 no-op。

InstallFatalHandlers(): 1. lock(GFatalMutex) 2. if bHandlersInstalled: return // 幂等 3. std::set_terminate(TerminateHandler) 4. bHandlersInstalled = true

ReportFatal(const char* Message)

← 公开 API · [[noreturn]] void

致命路径终点：输出到 stderr + 落盘 Fatal.log + abort。递归调用检测防死循环。

ReportFatal(Message): 1. Windows: SetConsoleOutputCP(CP_UTF8) // 控制台切 UTF-8，无控制台时 no-op 2. lock(GFatalMutex): if bInsideReportFatal: // 递归致命 → 直接 abort fprintf(stderr, "recursive ReportFatal") abort() bInsideReportFatal = true 3. Text = Message ?? "(null)" 4. fprintf(stderr, "Maho FATAL: %s\n", Text); fflush 5. AppendFatalLogFile(Text) // 追加到 Saved/Logs/Fatal.log 6. abort()

TerminateHandler()（内部）

匿名命名空间，仅被 std::set_terminate 引用

std::terminate 触发时提取活跃异常信息，转给 ReportFatal。

TerminateHandler(): 1. if 有活跃异常: rethrow + catch(std::exception&) → "std::terminate: " catch(...) → "std::terminate: unknown exception" 否则 → "std::terminate called (no active exception)" 2. ReportFatal(Message) // noreturn

AppendFatalLogFile(const char*)（内部）

匿名命名空间，仅被 ReportFatal 引用

AppendFatalLogFile(Message): 1. create_directories("Saved/Logs") // 忽略错误码 2. ofstream Out("Saved/Logs/Fatal.log", app) 3. Out << '[' << MakeTimestamp() << "] " << Message << '\n' 4. flush
