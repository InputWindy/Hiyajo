Async — API 文档

引擎的两种多线程模型 + 可运行契约。入口：Async.h（聚合头）· 概念见 Async.md

FThreadPoolclass

固定大小的线程池：N 个常驻 worker + 任务队列 + barrier。 用于瞬态并行任务（并行 for、job、短计算），不做常驻角色。

接口

签名说明
explicit FThreadPool(std::uint32_t NumThreads = 0) 创建池。0 = 硬件核数（0 则回退 1）。构造即启动全部 worker。
~FThreadPool() 停机：置停止标志、唤醒、join。队列剩余任务被丢弃。
void Submit(std::function<void()> Task) 入队 fire-and-forget 任务，立即返回。线程安全。
template <typename... FCallables>
void Run(FCallables&&... Callables) template		 所有 callable 并发执行 + barrier。0 个返回、1 个内联、N 个并发。
std::uint32_t GetNumThreads() const 返回 worker 线程数。

成员变量

字段类型说明
Workersstd::vector<std::thread>常驻 worker 线程
Queuestd::deque<std::function<void()>>任务队列（Mutex 保护）
Mutexstd::mutex队列互斥锁
CondVarstd::condition_variable唤醒 worker（新任务 / 停止）
NumThreadsstd::uint32_tworker 数量
bStoppingbool停止标志

ICommandLineinterface

命令行接收契约：所有可运行对象（工具包 / 引擎）在启动时接收原始命令行。 MahoMain / MahoCLIMain 创建后先调 ParseCommandLine 再驱动。

接口

签名说明
virtual ~ICommandLine() virtual 虚析构。
virtual void ParseCommandLine(int Argc, char** Argv) = 0 virtual 纯虚：解析原始命令行（如 CommandParser 插件实现键值存储）。

IRunableinterface

可运行契约：继承 ICommandLine。凡有主循环的类型（引擎、常驻线程）都实现它，供 app 侧统一驱动。

接口

签名说明
virtual ~IRunable() virtual 虚析构，可安全经接口指针删除。
virtual void MainLoop() = 0 virtual 纯虚主循环。FEngineBase 在调用线程驱动；FThreadedServer 在专用线程驱动。

FThreadedServerclass

专用常驻线程：单 worker + FIFO 队列。用于长命角色（渲染线程、IO、音频）， 继承 IRunable，可子类化重写钩子。不用于瞬态并行工作（用 FThreadPool）。

接口

签名说明
FThreadedServer() 默认构造，不启动线程。
virtual ~FThreadedServer() virtual 若仍在运行则先 Shutdown。
bool Initialize() 调 OnInitialize（失败返回 false），成功后启动 worker。
void Shutdown() 停止 + join + OnShutdown。排空队列：已提交任务跑完才退。
void MainLoop() override 常驻 worker 循环：取队列任务执行；停止标志 + 队列空时退出。跑在专用线程上。
bool IsRunning() const worker 是否在运行（原子读，跨线程安全）。
void Submit(std::function<void()> Task) FIFO 入队，非阻塞。线程安全。
void Flush() FIFO barrier：哨兵任务之前的任务全跑完才返回。
virtual bool OnInitialize() virtual protected worker 启动前调用，返回 false 则初始化失败。默认 true。
virtual void OnShutdown() virtual protected worker join 后调用，角色清理。默认空。
virtual const char* GetThreadName() const virtual protected 线程名（日志/调试）。默认 "ThreadedServer"。
