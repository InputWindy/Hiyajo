Async — API 文档

两种并行模型 + 可运行契约。

ICommandLineinterface

命令行接收契约：启动时接收原始命令行。

接口

签名说明
void ParseCommandLine(int Argc, char** Argv) virtual解析原始命令行

IRunableinterface

可运行契约：继承 ICommandLine。凡有主循环的类型（引擎）都实现它。

接口

签名说明
void MainLoop() virtual主循环
void RequestShutdown() virtual请求退出主循环（只有可运行的东西才有"停止"）

全局

符号说明
GApp（IRunable*）运行中的 app；FEngineBase 构造时置位，扩展经它请求退出

FThreadPoolclass

N 个常驻 worker 的任务池，瞬态并行计算。

接口

签名说明
FThreadPool(std::uint32_t NumThreads = 0)0 = 硬件核数
void Submit(std::function<void()>)提交 fire-and-forget 任务
template<Fs...> void Run(Fs...) template并行执行 + barrier；0 个直接返回，1 个内联

FThreadedServerclass

1 个专用线程的 FIFO 串行队列，常驻角色（渲染/IO/音频）。

接口

签名说明
bool Initialize()起线程 + OnInitialize
void Submit(std::function<void()>)FIFO 入队（非阻塞）
void Flush()FIFO barrier（哨兵任务排尾）
void Shutdown()排空队列后 join

子类钩子

签名说明
bool OnInitialize()线程内初始化
void OnShutdown()线程内清理
const char* GetThreadName()线程名
