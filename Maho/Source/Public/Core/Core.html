Core — API 文档

编译期 + 并发基础设施，零 app 假设、零三方依赖。

TTypeList<Ts...>template

编译期类型列表，调度器与拓扑的载体。

接口

签名说明
ForEach<TList>(Scheduler, Visitor)按调度策略遍历列表

TDependsPack<Slots...>template

依赖声明：继承在接口旁，声明 FDependsPack。

相关

类型说明
TDependsOn<Key, TList>一个依赖槽：在 Key，依赖 TList 里的每个类型
TPackConcat<Packs...>合并多个依赖包（子类扩展父类依赖表）
TResolveDependsPack<T>解析 T 的依赖包（无声明则空）
Topo::TLevels_t / TReverse_t编译期分层 / 逆序
Topo::TIsAcyclic_v编译期环检测

IExtension<TStage>interface

运行时扩展接口（非模板公共基类）：统一驱动契约。静态 TExtension、动态 DLL 插件、toolkit/engine 聚合都实现它。

接口

签名说明
virtual bool ExecuteStage(TStage) virtual每阶段行为

TExtension<TStage, TDerived>template

扩展基类：TSingleton<TDerived>（自带 Get()）+ IExtension<TStage>。

依赖在 public 继承列表显式声明：TDependsPack<...>。

FAssemblyclass

动态加载原语：句柄 + 符号探测。见 Maho.html。

FSerialTraversePolicy / FParallelTraversePolicystruct

遍历策略：串行（无线程）与并行（线程池 + barrier）。
