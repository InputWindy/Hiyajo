Core — API 文档

引擎的编译期 + 并发基础设施。入口：Core.h（聚合头）· 概念见 Core.md

TypeList — 编译期类型列表 + 运行时遍历

TTypeList<TTypes...>template

编译期有序类型列表（"类型数组"）。顺序有意义；遍历方式（串行/并行）由调用方选择。

接口

签名说明
static constexpr std::size_t Count类型数量

TTag<T>template

类型标签，让泛型 lambda 用 decltype(Tag)::Type 取回类型 T。

ForEach<TList>(Scheduler, Visitor, Args...)function

拆包 TList，逐个喂给 Visitor（TTag<T>）。调度器决定串行/并行。

签名

签名说明
template <typename TList, typename TScheduler, typename TVisitor, typename... TArgs>
void ForEach(TScheduler&&, TVisitor&&, TArgs&&...) template		 TScheduler 受 FForEachScheduler 概念约束

FForEachSchedulerconcept

调度器契约：对象有 Run(Callables...)。

约束

签名说明
requires(TScheduler& S) { S.Run([]{}); }需可被调用以执行 callable

Topology — 依赖声明 + 编译期拓扑算法

TDependsOn<SlotKey, TList>template

一个依赖槽：在 SlotKey 阶段，Self 依赖 TList 里的每个类型（peer 先于 self）。

TDependsPack<TSlots...>template

依赖槽的可变包。继承在接口旁，声明 FDependsPack。

TResolveDependsPack<T> / TDependsList<T, Key>template

解析 T 的依赖包 / 取 T 在 Key 阶段的 peer 列表（无匹配槽则空）。

Topo::* — 编译期算法namespace

图算法，输入都是 (TNodes, Key)。

接口

签名说明
Topo::TIsAcyclic_v<TNodes, Key>无环检测（bool）
Topo::THasCycle_v<TNodes, Key>有环检测（bool）
Topo::TTopoSort_t<TNodes, Key>线性拓扑序 → TTypeList<...>
Topo::TLevels_t<TNodes, Key>分层序 → TTypeList<TTypeList<...>, ...>
Topo::TReverse_t<TList>逆序一个 TTypeList（卸载序镜像）
Topo::TFindDependents_t<TNodes, Key, T>反向依赖：谁依赖 T（注册日志用）

Delegate — 单播 / 多播

FDelegateHandlestruct

多播绑定的句柄（Add/AddRaw 返回），用于 Remove。

TDelegate<Ret(Args...)>template

单播委托，一个绑定，可带返回值。

接口

签名说明
void Bind(std::function<Ret(Args...)>)绑 lambda / static / functor
template BindRaw(TObject*, TMethod)绑成员函数
Ret Execute(Args...) const调用（未绑定 = UB）
Ret ExecuteIfBound(Args...) const调用，未绑定返回 Ret{}
void Unbind() / bool IsBound()解绑 / 查询

TMulticastDelegate<void(Args...)>template

多播委托，N 个绑定，无返回值。单播 = 只 Add 一个。

接口

签名说明
FDelegateHandle Add(std::function<...>)加绑定，返回句柄
template AddRaw(TObject*, TMethod)加成员绑定（追踪对象）
bool Remove(FDelegateHandle)按句柄删
int RemoveAll(void*)按对象删（AddRaw 绑定）
void Broadcast(Args...) const快照广播（广播中增删安全）

Extension — 单例 / 扩展 / 调度器

TSingleton<TDerived>template

单例基类（CRTP Meyers）。扩展 / 全局单例继承它，自动获得静态 Get()。

接口

签名说明
static TDerived& Get() staticMeyers 静态实例（懒创建，线程安全）

EToolStageenum

单例生命周期（2 值 stage 枚举）：Init（正序初始化）+ Shutdown（逆序卸载）。

IExtension<TStage>interface

运行时扩展接口（非模板公共基类）：virtual bool ExecuteStage(TStage) = 0。 静态 TExtension 与动态 DLL 插件都实现它，PluginManager 经它统一驱动。

TExtension<TStage, TDerived>template

并行扩展基类：一组平级功能里的一员，由 stage 枚举驱动。 继承 TSingleton<TDerived>（自带 Get()）+ IExtension<TStage>（运行时接口）。

接口

签名说明
virtual bool ExecuteStage(TStage) virtual每阶段行为（调度器按依赖序调）

依赖在 public 继承列表显式声明：TDependsPack<TDependsOn<...>>。

FExtensions<TExtensions...>template

扩展列表载体：静态装配用。项目侧继承 FExtensions<FSystemA, FSystemB>， 继承到 FList = TTypeList<FSystemA, FSystemB>，供 Execute<Stage, FList> 驱动。

成员

成员说明
using FList = TTypeList<TExtensions...>装配好的类型列表

FSerialTraversePolicy / FParallelTraversePolicystruct

ForEach 遍历策略：串行 fold / 并行（持池 + barrier）。

接口

签名说明
void Run(FCallables&&...) const串行 fold / 并行派发

FForwardTopology / FReverseTopologystruct

拓扑 policy：正序（依赖在前）/ 逆序（依赖者在前，shutdown 用）。

接口

签名说明
template <typename TLevels> using Apply template恒等（正序）/ TReverse_t（逆序）

TScheduler / TSerialScheduler / TParallelSchedulertemplate

调度器层次：TScheduler（基类）→ TSerialScheduler（串行，无池） / TParallelScheduler（并行，持池）。串行 / 并行是编译期类型选择。

接口

签名说明
template <TStage Stage, typename TExtensions, typename TTopology = FForwardTopology>
void Execute() template		按依赖分层驱动 TExtensions（外层串行，内层按调度器串行/并行）

用法：Serial.Execute<Init>()（串行，无池）； Parallel.Execute<Shutdown, FReverseTopology>()（并行 + 逆序）。

Fatal — 致命路径（零依赖崩溃兜底）

ReportFatalfunction

统一致命出口：stderr + Saved/Logs/Fatal.log（std::ofstream 直接 append）+ abort()。不依赖日志系统。

签名

签名说明
[[noreturn]] void ReportFatal(const char* Message) 打印 + 落盘 + abort；线程安全 + 重入守卫
void InstallFatalHandlers() 装 std::terminate 兜底（幂等），main 第一行调用

MAHO_API / MAHO_EXPORT / MAHO_IMPORTmacro

DLL 导出宏（Export.h）。MAHO_BUILD_SHARED + MAHO_EXPORTS 时 dllexport， 否则 dllimport；静态构建全空。

Async — 两种并行模型

详细 API 见 Async/Async.html。

FThreadPoolclass

固定大小线程池：N worker + 任务队列 + barrier。瞬态并行任务。

FThreadedServerclass

专用常驻线程：单 worker + FIFO 队列。渲染/IO/音频角色，可子类化。
